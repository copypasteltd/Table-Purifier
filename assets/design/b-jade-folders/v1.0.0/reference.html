B-C29 搜索筛选与分页

状态：available / restricted / not-approved / version-limited

状态：diff / stale / conflict / resolved

18页定型规则

根导航固定为整理、任务、规范、我的。列表与问题是手机主操作形式；宽表按需选列，不要求用户逐格审阅正常数据。

资料清单		继续检查白底列表，不给每文件再加资料夹页签；已完成项保留，失效临时文件需重选。普通文档入口仅按能力开关显示。移除已冻结来源先说明范围影响；规范文件单列不当事实。规则定型，尚无独立图稿
MP03
规范输入		使用此规范我的规范/获准上传/字段编辑三种来源。沿用B字段目录，不强迫逐列来源映射。带样例解释而非事实；未明确粒度/关键约束时澄清，不以付款默认同意。规则定型，尚无独立图稿
MP04
预检与报价		确认并开始一次只突出当前合法启动动作；获准交易用对应平台收银，免费许可标明免费。报价变更再确认；局部预检标范围；不可收费环境不引导外站付款。费用/保留/修订无需藏在长文本末端。规则定型，尚无独立图稿
MP05
处理进度		查看待办（有待办时）用阶段列表和文本状态，普通处理中无强制主按钮，可离开。WAITING_SCHEMA指向MP06；需要补值指向MP09。系统错误提供恢复/帮助，不把手机退出当取消。规则定型，尚无独立图稿

推荐规范		采用规范严格参照B三页中间图视觉；三字段只是9列示例，必有看全部入口。全范围草案可采用，局部只能查看/继续分析；显示未映射重要信息。采用前可调，绑定确切版本。三页图像参照之一
MP07
字段编辑		预览修改字段多时分组折叠；规则和单位有可见标签。删列、粒度、单位、必填/键变化先看影响后保存；不按拖动唯一操作。不改变本地草稿直到明确保存。规则定型，尚无独立图稿
MP08

MP09
问题列表		处理下一项（有待办时）缺项/冲突区分文案。批量只对相同规则/语义，提交前看数量和例外，不能猜定全部冲突。返回MP08保留筛选及位置。规则定型，尚无独立图稿
MP10

MP11

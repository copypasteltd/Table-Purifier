# 表格修复站：计费、交易与运营

> 历史v2.1：2026-10-27由“小程序优先、Web进阶”的v3.0替代，保留当时网页优先方案。当前需求见[PRD](../../01-产品需求PRD.md)。

P07｜v2.1｜2026-10-27｜多源资料按用户规范成表。所有金额、期限和预算为设计要求/待实测配置，不是已销售服务。

## 售卖单位与报价

售卖单位改为一个“资料集合＋规范模式/版本＋目标说明＋处理预算”的整理任务。可以包含多份文本/附件、跨文件信息与同一次结果验收。旧P07-ORDERS-1000-V1与1.9元单表价格退出当前方案；新SKU按支持的输入范围、OCR/模型预算及修订义务发布。

报价需列源清单、排除项、PROVIDED/DISCOVER模式及已知规范版本、费用总额/上限、处理单元和候选上限、计算时限、结果政策、含修订轮次、下载与数据期限。15分钟有效，前端不能传入可执行价格。定价先测成本，不能声称多份PDF/图片也已验证可按1.9元交付。

预检/目标解释免费，最多3来源单元的可选预览明确非全量；未购买预检按租户限流，初始每天5个新任务，缓存复用不多算。全范围结构发现/抽取在确认报价后执行，不能先做无限全量免费计算再假设付费必能回收成本。DISCOVER报价包含规范设计、首次采用与模板交付；先绑定源/目标/模式/预算，采用规范以追加记录绑定，不改旧支付摘要。没有模板不是错误或隐性加价理由。

## 两种结果政策

用户提供并明确的规范，或系统推荐后由用户采用的规范是验收基准；规范合理性与重要信息覆盖另查。默认STRICT_STANDARD，不把生成一个文件称为合格。用户可在购买前选择BEST_EFFORT_REPORT，清楚接受“完整结构＋已有信息＋缺项/冲突报告”作为该服务交付，不能执行后替用户切换。

| 政策 | 合同目标 | 未满足时 |
| --- | --- | --- |
| STRICT_STANDARD（默认） | 约定资料范围处理完成，候选/证据核对和规范验收通过；包含24小时两轮补确认 | 平台错误免费纠正；来源不足/冲突在窗口结束仍无法通过则全退，停止后续新权益 |
| BEST_EFFORT_REPORT（主动选择） | 对已约定输入完成提取整理、来源覆盖与问题报告；允许待补充 | 来源本来缺信息不自动退款，仍须完整报告；平台漏读/错误/坏文件不能借此免责 |

两种政策都须有已明确/采用的规范；无模板模式在窗口结束仍无法提供可采用规范或未采用则不能完成合同，按实付全退，不靠放宽标准或只给无关表头收费。两种政策下0条候选均不收费/已收全退，不收“空表成功费”。超限或无法执行原合同，用户可主动确认分批新合同；不接受则终止并退，不能偷截断后收费。全部未通过但存在候选的尽力报告，必须在购买前明示这一可能与价值范围。

## 支付、执行与修订分离

Machine Pay按实际获准SDK验证授权/验付/执行/结算。任务处理成功、规范验收通过、最终结算成功和退款到账各自记录。网页入口的支付适配若与Agent不同，另确认获准通道，保持相同订单合同。

人工补确认窗口不等于支付授权可保持24小时，不假定平台具有预授权/托管能力。上线前验证“处理服务＋问题工作区＋后续修订/退款”的可用时序；无法适配则先调整正式方案，不收款伪装已集成。

同任务网络重试、状态查询、下载、平台纠错不重复收费。相同源集/已采用规范，首次可审阅工作区起24小时内含规范采用和最多两轮用户修订与自动复验；一次修订由用户合并提交若干决定，显示剩余轮次与影响范围。平台失败可恢复同一修订，不重复耗次，纠错不占次数。支付成功不视为用户已经确认未知规范。

PROVIDED首次工作区为首版结果；DISCOVER首次工作区为全范围规范草案及预览就绪，统一显示起止时间。首次规范采用及采用前同目的调整不占两轮、不新增收费，人工等待不计计算超时。新增资料/改变原用途先说明新范围；采用后用户主动改规范/粒度，展示影响与报价，原合同内修订和平台漏识别免费纠错不冒充新需求。用户关闭问题弹窗不视为同意以猜值解决；保持待补状态。STRICT窗口结束未通过自动进入退款，不强迫用户提供并不存在的信息。

## 事件决策

| 事件 | 收费/处理 |
| --- | --- |
| 无资料或无可读来源 | 不创建付费执行；提示补充 |
| 无规范 | 进入DISCOVER，不要求用户手工做表；全范围分析/推荐包含在报价中 |
| PROVIDED规范关键含义无法解释 | 先必要澄清；不能把付款当作已确认，可主动切换DISCOVER |
| 某附件不可读 | 报价前提示；用户转换或明确排除后重定范围 |
| 付款未知/回调缺失 | 查原交易，不重新收同任务费用 |
| OCR/模型/导出失败 | 阶段重试一次；仍不能履约退实付/按SDK终止未结算授权 |
| 提取不到任何候选 | 全退，报告原因；不伪造一行数据维持成功 |
| 来源缺失或冲突 | 保留问题并允许含轮次补确认；按选定结果政策履约/退款 |
| 处理超时/预算耗尽/发现超范围 | 停止新增计算，解释范围，原合同不能完成则退；不临时加价 |
| 用户明确改了要求 | 新报价；原任务是否继续/取消事先说明，平台纠错不归入新需求 |
| 取消与完成并发 | 服务端条件更新确定最终分支，查询和权益一致 |
| 退款已申请 | 显示申请/处理中；通道确认前不标已到账 |

QUOTE/ORDER/RUN/RESULT/REFUND各有编号和幂等约束。原支付流水唯一归属，累计退款≤实付；已下载文件不能收回，退款后撤销未来链接/继续处理权益。无最终扣款不能伪记退款收入或退款到账。

## 成本与质量运营

成本包含预检分摊、文档解析、OCR页/图片、结构发现/规范草案及调整、必要模型文本/视觉调用、归并校验、存储下载、失败重试、两轮修订、支付费、退款损失和支持。免费任务成本与严格模式退款成本都计入，不只计算通过任务的一次推理。

按任务报告实收、退款、变动成本与贡献，不把贡献当净利润。分别观察原始资料种类、规范复杂度、推荐规范采用/调整、关键字段覆盖、粒度错误、未纳入重要信息、字段准确率/记录召回率（标准集）、冲突漏报、人工纠正量、运行成功率/验收通过率、真实使用与复购。不能以解析页数覆盖率替代语义质量。

后台能按源集/规范/结果版本查问题与成本，暂停出错解析器/模型版本的新单，既有查询/下载/售后继续。客服默认看摘要，查看内容要权限与理由；公开演示只用合成或另获授权资料。

## 保存与清理

| 数据 | 保存策略 |
| --- | --- |
| 未购买资料与模板 | 上传24小时后清理在线源内容，草稿只留不含正文的摘要 |
| 已运行来源/模板/OCR/解析片段 | 初始处理与24小时修订窗口结束后再保留24小时；最迟首次可审阅工作区后48小时；不得在含修订窗口中提前删除 |
| 运行失败/取消且无结果 | 终态后24小时清理，必要故障摘要脱敏 |
| 付款/结算未知但有产物 | 不无限保留；按首次可审阅工作区后48小时清源、7天清结果；恢复付款不能突破内容期限，必要时退款 |
| 规范草案/预览、结果、问题和证据摘录 | 各内容版生成后7天，显示明确到期时间；可能含原值，提前告知 |
| 可复用空模板 | P0随结果供下载本地复用，剔除真实值/证据/访问引用；在线与结果一起到期，长期私有模板库另行设计 |
| 交易凭证/日志/备份 | 共用规范按实际主体与合同，内容清理标记防恢复重暴露 |

源文件清理后可能仍有报告必要摘录在7天范围内；不能宣传已清空所有原信息。默认不用于平台训练/宣传；上游处理方的留存与训练条件按实际合同告知，不凭本地设置宣称第三方零留存。

# 表格修复站：小程序数据、隐私与安全

P07｜v3.1｜2026-10-27｜产品与工程要求，不代表已完成合规审核或安全测试。关联P07-F01、F20、F26、F34、F39—F41。

## 数据清单与处理目的

| 数据 | 目的与最小范围 | 访问与风险 |
| --- | --- | --- |
| 平台身份/会话 | 登录、归属校验；provider/app/subject及必要会话 | 服务端受控，临时凭据不进正文日志 |
| 文本、原件、规范文件 | 本次解析、规范理解、整理和核对 | 可能含个人/商业信息，默认私有 |
| OCR/页图/提取片段 | 定位、抽取和证据展示 | 仍为原内容，不能当无敏感中间件 |
| 规范提案/结果/问题/证据 | 用户采用、审阅、交付和修订 | 真实预览/摘录同样需要授权和到期 |
| 主动另存私有规范 | 后续复用字段/规则 | 不含来源事实/引用；字段名、规则也可能敏感 |
| 订单/支付/退款 | 履约、对账、售后 | 与正文分离，必要留存依实际合同/要求 |
| 内容无关运行日志 | 排障、成本和性能 | 不记录原文、手机号、文件正文、令牌、签名链接 |
| 客服附件/访问记录 | 经用户授权处理具体故障 | 最小摘要默认，正文访问有理由/期限/审计 |

真实客户材料不放公开assets、错误示例、平台审核截图、统计仪表盘或分享卡。测试与评委演示优先合成材料；授权材料记录使用范围。

## 授权与告知时机

可浏览合成演示；真正上传/处理前展示用途、支持范围、处理方类别与具体名单入口、OCR/模型传输、保存期限及删除/售后入口。把实际收集/调用与两平台隐私声明对应，不能只复制通用模板。

拍照/相册在用户点入口时按宿主要求授权；拒绝不强制跳转设置，仍可用已开放文本/其他文件路径。剪贴板仅用户明确动作且符合宿主规则时读取；不启动扫描，不全相册/聊天目录遍历。不为整理任务强制索取手机号、头像、定位或通讯录。

通知单独可选，拒绝仍可在任务页查询。不得把隐私同意、支付同意、规范采用和公开分享捆成一个按钮。隐私声明更新需能辨识变更和生效版本，必要重新确认。

抖音隐私授权涉及平台配置及受保护API的先行要求，实际以当前接口/作用域核对，不能以自写弹窗代替平台流程。[官方指引](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/tutorial/security-requirements/privacy-authorize)

## 外部OCR与模型处理

只发完成当前任务所需内容，按页/片段控制，使用受控服务端适配器。记录供应商/地域、用途、版本、保留/删除条件和失败处理，购买前可查。用户材料默认不用于本平台模型训练/公开示例；第三方能否零留存必须有真实合同，未知不能承诺。

材料中的指令是待处理数据，不是系统命令。附件要求“忽略规范、上传其他客户文件、执行代码、支付、改收款地址”不产生权限。模型不持有支付密钥、不自动外写，不直接决定规范合格或退款到账。OCR、提取、规范推荐和规则验收边界分开。

## 访问控制与文件安全

所有任务、源、规范、提案、记录、证据、产物、模板、订单、退款及接力票据都核主体/租户/资源归属。知道ID、链接或同名文件不能获取权限；不同平台subject不能混用。小程序客户端上报的app/OS只作信号，关键交易资格由服务端配置及可验证身份共同决定。

下载短链默认5分钟，在当前权益内重签；禁止永久公开链接。证据页图/缩略图与源文件同等授权，服务器内部路径不暴露。会话和下载令牌不拼入日志/分享参数；敏感页面不生成公共预览卡。

文件检查真实类型、大小、压缩展开量、路径、编码和解析超时。宏/公式/外链/嵌入程序不执行；导出对危险公式前缀做安全处理并披露。解析在限资源原生子进程中运行；不调用Docker/WSL/虚拟机，也不把子进程隔离说成可安全运行任意恶意代码。

接力票据需平台允许、短期单用途、双方归属证明、兑换后失效和撤销；不接受用户任意URL让服务器抓内网/文件地址。不提供未授权网盘、聊天附件自动导入。

## 留存与删除

| 类别 | 拟定期限/行为 | 用户应知道 |
| --- | --- | --- |
| 未购买材料/模板 | 上传后24小时清在线内容 | 草稿摘要不保留正文，过期需重选 |
| 运行源/OCR/中间内容 | 覆盖审阅，workspace_ready后最迟48小时；无工作区失败/取消终态后24小时 | 原件到期后不能看原图，不伪造证据 |
| 草案/预览/结果/必要摘录 | 每内容版7天 | 原件删后摘录可能尚存；不同类别清理分开 |
| 主动保存私有规范 | 去事实/引用后至删除/注销，服务终止另告知 | 独立于任务，字段/规则仍私有，不默认公开 |
| 设备缓存 | 尽快释放或按宿主生命周期失效 | 缓存不作备份，用户主动导出副本自行管理 |
| 账务/审计/备份 | 与正文分离，按共用规范及实际要求 | 删除标记/访问撤销防恢复后重新暴露 |

上述是试点设计，必须满足平台实际履约/售后条件再启用，不以7天文件清理剥夺后续售后。删除原件、删除整任务内容、删除私有规范、注销账号是不同动作，明确影响和不可恢复内容。删除任务不自动删除已独立保存的规范；用户可选择一并删，不默认替其做选择。

保存到私有规范需生成白名单快照：字段/类型/单位/约束/粒度和已明确业务规则；去掉真实样例、证据片段、文件/页引用、个人值、task/source访问ID和签名。规则中用户明确要求的敏感枚举也按敏感私有数据处理，不能因叫“规范”就公开。模板文件导出同样做检查。

清理含对象、数据库内容字段、搜索/缩略缓存及供应商可执行删除请求；记录不含正文的清理结果和失败重试。备份轮换遵循共用规范，恢复必须先重放删除/撤权标记。第三方不可即时删除时按真实能力告知，不虚报“所有副本立即清空”。

## 安全与隐私验收

两租户互换所有资源ID/链接均拒绝；拒绝图片/隐私/通知授权有正确路径；前后台/退出不泄漏资料；源注入不能改规范/权限/支付；坏文件/炸弹超限不执行；导出无公式执行；日志/客服/审核材料无意外正文；原件清理后私有规范仍可用且不带事实；删除模板和注销撤权有效。所有条目待实施后验证。

发生越权、隐私泄漏、无标记捏造、错归并或资金错误，暂停相关新处理/收费，保留订单查询和售后；按实际事件修复、通知和退款要求执行，不能仅改演示数据掩盖缺陷。

## v3.1数据删除和进行中履约

删除动作分“只删原件”“删任务全部内容”“删私有规范”“注销账号”，每次给清楚对象、影响、不可恢复内容和必要保留类别。进行中任务先暂停/撤内容权限并协调取消、原路退款或获准继续履约；不把删除当作放弃退款，也不静默继续调用模型。

写tombstone后访问立即按撤权判定，清理任务异步幂等：对象/数据库正文/页图/检索/缓存/供应商请求逐类记结果。候选撤访问≤1分钟、在线清理≤24小时、备份轮换30天需要实际合同与实现验证，不承诺第三方所有副本即时清空。恢复先重放tombstone再开放。

客服授权必须绑定工单/资源/用途/期限，默认只摘要；用户可撤销，访问审计不含全文。导出的本地副本不能远程回收；源已清理但摘录仍在必须显示类别区别。具体处理方、地域、供应商保留及法定/平台账务期限仍是待锁定依赖。

# 表格修复站：接口载荷与状态合同

P07｜v3.1｜2026-10-27｜自有API合同草案，未实现；不是支付宝/抖音SDK或完整运行OpenAPI。53项资源操作与[机器目录](../../assets/contracts/api-catalog.v3.1.json)一一对应，示例见[payload JSON](../../assets/contracts/payload-examples.v3.1.json)。

## 统一请求、响应与授权

前缀/v1/p07。所有业务资源归属从服务端会话判定，不接收可越权tenant_id；内部能力查询仅运营角色；platform-events用平台验签而非消费者session。真实SDK载荷由正式适配器处理，不推定两平台同字段。

GET读资源不产生收费、修订扣次或新执行。写操作带Idempotency-Key（作用域owner+action，建议随机UUID）与规范请求摘要；同键同请求返回原resource/operation，同键不同请求409。客户端请求ID只作关联，不当授权。重试保留原键，确认是新动作才换键。

版本修改携带expected_*_version，草稿任务/源变更、规范采用、决定提交、取消/删除、新模板版都需核对应当前版本。对已有结果的只读请求显式result_version；cursor绑定owner/version/filter/sort，默认20/最大100，版本变化不能混页。

标准响应含request_id、resource、current_version、allowed_actions；异步写返回202+operation_id，可查P07-API26。同步成功201/200或删除204按实际动作；PENDING是业务状态，不能作为error_code宣称失败。客户端超时先查原operation/订单，缺operation_id时以同幂等键查询原请求或安全重放同载荷找回，不新建收款。

数值：decimal字段字符串，标识文本，支付整数amount+明确unit；缺失null+status，0/false保留。时间UTC ISO8601，所有deadline服务端计算；未启用窗口返回null+policy说明。来源位置/原文访问有类别与期限，不返内部路径/机密/堆栈。

## 资料、范围和报价

上传许可只授当前任务/角色、字节/类型/有效期，complete由服务端重核原件hash/mime/bytes/归属；本地临时路径不是服务器凭据。文本按Unicode码点校上限；不接受任意URL供服务器抓取。冻结后移除/增加源走新范围确认，不修改原合同。

Preflight返回readability、included/excluded/undecided源、billing_units、sample_scope(max3)、partial_proposal及必要clarifications，不声称全量规范。confirmation包含source_set/goal/模式与政策版本/排除确认/PROVIDED规范；DISCOVER不要求standard_id。quote必须返回原单位显示价/总上限、有效期、交付路径、采用/修订/退款与内容保存政策。

订单与run创建都可幂等找回既有资源。没有已核实付款或明确free_grant不得履约；免费不映射CONFIRMED现金。原支付面板信息/类目/OS资格由服务端核准，未知/晚回调保留原订单事实。

## 规范提案、变更和采用

提案含proposal_version、scope/source_set/goal、PARTIAL_DRAFT/FULL_DRAFT、row_kind、field_suggestions、coverage/unmapped_important_information、preview_scope。字段至少field_id/label/type/required/nullable/unit/order/description、建议规则reason/evidence/counts；样本中出现不等于必填唯一。

采用请求：

```json
{
  "expected_proposal_version": 2,
  "source_set_version": 1,
  "goal_version": 1,
  "action": "ADOPT_PROPOSAL"
}
```

事务校归属/FULL/源目标版本→写不可变schema_version/binding及采用审计→恢复执行事件。同键重试返回原Binding；旧proposal/新增源409，不自动改到最新版本。变更建议先预览差异/影响，不用自然语言直接改最终验收。

## 决定、预览、提交与修订

预览请求：

```json
{
  "expected_result_version": 2,
  "decisions": [
    {
      "issue_id": "issue_price_missing",
      "record_id": "record_baishi",
      "field_id": "price",
      "action": "USER_VALUE",
      "value": "28.50",
      "unit": "元/件",
      "note": "由资料所有者补充，非原件提取"
    }
  ],
  "scope": {
    "record_ids": [
      "record_baishi"
    ]
  }
}
```

CHOOSE_EVIDENCE需要合法候选证据；USER_VALUE需要符合字段type/unit和可见来源说明；KEEP_UNRESOLVED不消除原问题。初始没有action；空值/非法输入不生成已提交决定。明确批量范围可用record_ids或冻结筛选hash+版本+数量，必须列例外，不能动态“当前全部”变成隐式全选。

预览返回preview_id/hash/父结果版本、影响数量、例外、是否用户轮次/平台纠错及剩余额度。提交需preview/hash/expected_result_version，不允许在预览后静默改变scope。服务端一事务保存DecisionBatch/Operation、预留一次轮次、创建子Run；成功发布新结果才消耗，永久失败释放。

/revisions只针对既有DecisionBatch找回/重试复验，与/decisions共享batch唯一约束和原Operation，不第二次创建同一修订或扣次。一次已成功batch不能用换幂等键重跑收费；新决定要新预览/父版。Operation永久FAILED保持终态，明确获准重试创建retry_of新Operation，沿用batch唯一约束及轮次记录；临时阶段重试仍属原PENDING Operation。

## 文件领取与私有规范

artifact列表同一版本固定9项artifact_id/name/bytes/hash/expires/quality/availability，manifest内部仅核其他8项，自身hash外层返回。READY才可发短链；默认300秒，续签重新核owner/权益/到期/撤权。源/结果/合同期限不混为签链TTL。默认短链通过自有授权下载网关兑换，每次新请求校删除/退款/撤权，不直接暴露无法提前撤销的桶长链；已开始传输或用户副本不宣称可远程回收。

export-attempts只记观察action与receipt_source=CLIENT_OBSERVATION/USER_CONFIRMATION/PLATFORM_RECEIPT，平台无回执不填PLATFORM_CONFIRMED。失败/未知重试领取不重开run。

另存私有规范须用户主动、选确切Binding及名字，服务端白名单快照去真实值/证据/任务源ID/签名，敏感字段名仍隔离。新模板版本不改旧任务，复制新template_id；删除使未来不能选用，不改历史已用SchemaBinding。

## 错误与恢复

| HTTP / code | 含义 | 客户端恢复 |
| --- | --- | --- |
| 401 SESSION_EXPIRED | 会话已失效 | 重新核原身份再查原任务/动作 |
| 403 RESOURCE_FORBIDDEN | 非本人/无权益 | 不泄露资源存在细节 |
| 403 CAPABILITY_UNAVAILABLE | 当前环境/SKU未开放 | 显示原因，允许路径内降级，不引导外站付款 |
| 409 VERSION_CONFLICT / CURSOR_VERSION_CONFLICT | 旧提案/结果/草稿/游标 | 保留未提交稿，刷新比较，不最后写覆盖 |
| 409 IDEMPOTENCY_CONFLICT | 同键不同请求 | 停重放查原动作，不自动换键 |
| 410 CONTENT_EXPIRED | 指定类别已到期 | 说明原件/摘录/结果区别，订单售后仍可查 |
| 413 SOURCE_LIMIT_EXCEEDED | 文件/文本已超限 | 报价前提示，不截断 |
| 422 UNREADABLE_SOURCE / INVALID_DECISION | 不可读/决定值或证据非法 | 修输入，保留可恢复上下文 |
| 422 SCHEMA_REQUIRED | PROVIDED目标尚未明确 | 完善目标或用户主动换DISCOVER；DISCOVER不得因此被阻断 |
| 422 BUDGET_EXCEEDED | 新开销超合同 | 停新增计算，范围/原合同处理，不自动加价 |
| 429 RATE_LIMITED | 预检/接口频次限制 | 返回范围和可重试时间，不静默转付费 |
| 503 DEPENDENCY_UNAVAILABLE | 依赖临时不可用 | 按阶段预算恢复，原支付/动作先查 |

错误含request_id/error_code/user_message/retryable/current_version/allowed_actions，示例见payload文件。GET order中的PENDING/UNKNOWN用正常响应呈现，未确定不映射支付FAILED。真实宿主错误另映射并保存脱敏原码。

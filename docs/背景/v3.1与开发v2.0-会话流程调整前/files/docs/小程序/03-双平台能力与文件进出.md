# 表格修复站：双平台能力与文件进出

P07｜v3.1｜2026-10-27｜设计与发布门槛。官方资料和不确定项见[核对记录](../资料/双小程序官方能力复核-v3.1-2026-10-27.md)。当前没有双端真机证据，以下目标不代表API已经接通。

## 必须分开的四种能力

| 能力层 | 问题 | 证据 |
| --- | --- | --- |
| 服务端解析 | 系统是否能读这种格式并定位来源 | 真文件、解析版本、标准答案与失败样本 |
| 手机选取 | 该平台/OS能否由用户选择所需文件 | 目标宿主官方能力、真机入口和权限记录 |
| 传输/保存 | 本地文件能否上传或取回，临时路径/缓存有何限制 | 正式域名、大小/网络/生命周期实测 |
| 预览/实际导出 | 用户能否看内容并取得可继续使用的文件 | 内嵌预览、宿主打开、真实导出路径分别有证据 |

后端支持DOCX不证明手机有Word选择器；上传API接收本地路径不证明能选任意办公室文件；下载/缓存成功不证明用户已保存到手机可见目录。这四层分别进入能力开关和发布报告。

## 能力状态与发布单元

统一记录DESIGNED、DOCUMENTED、NEEDS_VERIFICATION、CONFLICT、TESTED_PASS、TESTED_FAIL、UNAVAILABLE。DOCUMENTED只说明在特定官方文档范围有依据，仍需实际目标端验证；若实际存在CONFLICT先取得适用解释；本轮iOS两个入口已一致，不再延用旧冲突。

按支付宝Android、支付宝iOS、抖音Android、抖音iOS分别记录host版本、基础库、设备/OS、应用ID/环境、入口、测试人/日期、证据和支持限制。当前四单元都未测试，关键开关默认false，不能把配置文件当作能力证明。

| 目标 | 支付宝境内小程序 | 抖音小程序 | 产品处理 |
| --- | --- | --- | --- |
| 平台登录、隐私 | 官方入口已定位，具体国内SDK和授权待核 | 官方登录/隐私接口有文档，仍待接入 | 分别服务端校验，不拿同名SDK互代 |

抖音openDocument文档列doc/docx/xls/xlsx/ppt/pptx/pdf，同时说明端侧差异，包括iOS的ppt和Android的小程序内预览限制；这是该接口的官方说明，不是所有机型实测结果。[官方文档](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/api/file/tt-open-document)

## 输入路径与降级

1. 文本：用户主动输入/粘贴，客户端显示字数，服务端收到后才标已提交；不在日志中输出正文。
2. 图像：用户主动拍摄/选取；可显示页序与清晰度提示。不用改变文字可读性的强压缩偷偷减费；客户端必要处理保留操作说明和来源关系。
3. 普通文档/规范：先按平台已获准入口选择，再做真实类型、大小及传输验证；未知入口不显示虚假按钮。不同来源角色单独标记，规范样例不进入事实。
4. 我的规范：直接引用私有规范不可变版本，无须重复上传Excel；仍说明采用范围。
5. 辅助接力：只有平台允许且经过安全/真机验证时开放指定任务文件接力/领取页。普通文件入口没有合法路径时，应限制该端内测范围，不能以“以后用网页”宣布小程序P0全部完成。

接力不是自动抓URL、网盘或聊天。若获准，用户从已登录任务主动发起，服务端签发短时、单用途、绑定任务/动作/主体的票据，经安全二次证明兑换一次会话；不把账号凭据放URL。页面不含支付跳转、进阶编辑、第三方广告或跨用户搜索。票据初始TTL建议5分钟，兑换后立即失效，继续上传另获有限会话。此为自有安全设计，不代表宿主允许其跳转/扫码方式。

仅凭task_id、文件名、知道链接或扫码不能拿到任务/结果。兑换需证明原用户持有，明确显示目标任务/动作并可撤销；同一浏览器保存的会话也不能跨租户复用。文档明确登录或接力机制未验证时关闭该路径，不创建长期公开下载链接。

## 上传与预检合同

上传状态为选择中→等待→传输中→服务端已接收→校验成功/不可读/失败。宿主返回传输成功后，服务端还要验证大小、真实类型、内容哈希、归属、恶意内容及解析范围。客户端显示已接收不等于已解析。

队列默认有限并发、可取消单项和重试失败项，不把一次API调用误写成10文件批传。文件临时路径仅端侧使用，回到前台检查有效性；失效需重选，与已上传文件摘要匹配后继续。不承诺后台上传或平台未提供的断点续传；已有完成项不重新收费计量。

后端预算10文件/单20MB/总50MB、模板5MB；客户端仍遵守平台更低实际限制。不得为了满足后端预算把全部原件长期放应用缓存。单文件进出逐项处理，按需页图和记录分页。上传域名、下载域名、HTTPS和正式环境校验需配置并真机验证。[抖音上传说明](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/api/network/http/tt-upload-file)

范围预检说明：可读页/块、无内容/坏文件、排除/超限、模板角色与计量；免费最多3单元建议必须标局部。用户确认排除或分批才更新合同。不静默忽略失败文件、不只按扩展名判定、不执行宏/内嵌程序/外链。

## 预览与证据

结果卡、问题列表和选列表格由分页业务数据渲染，原生XLSX查看器只是可选便利。证据用必要文本片段/授权缩略页图/单元格定位，按需加载，可放大并显示页号。没有宿主原生预览不妨碍看结构化结果，但不自动解决文件交付。

原生打开失败记具体错误，回到内嵌预览，不提示“文件损坏”除非已证实。预览图和摘录仍可能含个人信息，与结果同等授权/到期处理，不上传公共图床。

## 实际交付状态

| 阶段 | 允许表达 | 不允许推断 |
| --- | --- | --- |
| ARTIFACT_READY | 服务端结果文件已生成 | 用户已收到 |
| FETCHED | 客户端已获取文件 | 已存系统下载目录 |
| CACHED | 已保存小程序内缓存及具体位置说明 | 已永久保存或可在其他App打开 |
| OPEN_REQUESTED / OPENED | 已发起/已打开宿主预览，按实际回执区分 | 已导出/已分享成功 |
| EXPORT_REQUESTED | 已启动已获准导出动作 | 任何场景都得到操作系统保存证明 |
| USER_CONFIRMED / PLATFORM_CONFIRMED | 用户确认已取用 / 宿主明确回执成功 | 用户确认与真实系统回执相同 |

自有接口记录的是上述观察，不制造宿主不存在的回调。验收由测试人员证明用户可在指定目标位置访问Excel并核内容/版本；所有“保存成功”文案必须匹配真实含义。重复领取仅重签权限内短链，不重跑不重新收费。

主交付按钮3个，其余6文件放更多；manifest覆盖其他8文件，自身哈希由接口提供。手机不必一次取九文件，但后端合同完整。过期在线链接、来源清理、退款权益变化、格式校验错误分别提示；尚有权益且文件未到期可重新申请，不发公开长链。

## 完整P0的阻断条件

任何发布单元缺少经过批准和真机证明的资料/规范导入、手机问题处理、真实Excel取用路径，不能称该单元完成完整首版。仅文本/图片内测必须明确受支持范围，不收费出售尚无交付路径的文件服务。发现商业类目、隐私或交易不适用时关闭相关新单，保留已有订单查询和售后。验收证据详见[双端发布清单](06-双端验收与发布清单.md)。

## v3.1上传与导出补充合同

上传依次创建本任务有限许可、单文件传输、服务端complete重算hash/type/bytes、登记SourceAsset、明确角色后进入SourceSet。传输回调成功不等于校验/可读；旧许可/超字节/他任务摘要拒绝，重复complete回原资源。精确字节/码点/块计量见[引擎规格](../需求深化/03-整理引擎与规范验收规格.md)。

手机每次只取必要文件/页图，达到较低宿主缓存限制时释放不用项，不能强下载50MB全套。下载短链有效期与内容/权益到期不同；设备导出失败不再计算收费。三主文件的真实目标位置取用证据是G06，普通文档/模板选择是G03，二者都未真机前不宣称完整P0。

当前iOS两官方规范入口已一致，商品/支付开通仍待证；S06已读developer正式页，partner抓取超时不推断API失效。[本轮官方复核](../资料/双小程序官方能力复核-v3.1-2026-10-27.md)。

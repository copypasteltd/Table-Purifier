## 首页与输入

首页一句话说明：“把零散资料整理成表；没有表格模板也能开始。”突出添加资料。模式显示“帮我生成规范 / 我有规范”，无模板可直接继续，切换后不删除已上传材料，只调整标准来源。

文字输入有可见标签、字数/上限、保存状态，不能只有placeholder。读取剪贴板必须由用户点击明确按钮且满足宿主授权；默认用系统粘贴，禁止启动时扫描。图片入口让用户主动拍照/选取，拒绝授权仍可粘贴或用已开放文档路径。

资料卡显示“待上传/上传中/已接收/不可读/已排除”，失效项点开可重选。原件和规范角色不可混淆；同名不覆盖。删除已计价来源、追加来源需提示是否改变合同，不能静默扣费。

## 两条示例任务

有规范：添加两份报价材料→选择“我有规范”并导入字段规范→确认一行是一次商品报价→预检及购买→自动填写→处理“税率冲突”→领取结果和空规范。正常型号/数量无需逐条批准。

无规范：添加报名文字与照片→选择“帮我生成规范”→可不填用途→预检及购买→系统建议“每位报名者一行，姓名/电话/场次/备注”→看来源和未纳入信息→采用→整理→补一个缺少场次的记录→领取。不得从少量样本推断电话必然唯一或每列必填。

## 推荐规范与修改

顶部先展示“一行代表什么”和字段组，手机默认不铺开50列表格。字段卡显示名称、解释、类型/单位、建议规则及简短理由；展开看来源分布/依据。预览是代表性记录，标明抽样范围，不能把3条写成全量。

常规重命名/说明更新保存草稿；变更行粒度、删列、必填/唯一/枚举、单位和归并键时展示影响摘要：“影响多少记录、哪些信息会移出、是否需重新提取”。采用前原用途内调整不扣修订轮次，冻结后变化按合同解释。移除难填字段不能自动制造通过。

字段排序同时提供上移/下移，不依赖拖动细小手柄；50字段可分组折叠、搜索和逐项编辑。自然语言指令先生成变更预览，用户确认后才采用，不让含糊一句话静默重设验收。

## 记录、问题与来源的联动

```text
结果概览  128条候选 / 116通过 / 8待补 / 4冲突
[全部] [待补] [冲突]  搜索记录
┌ 张某 · 报名场次待补 ┐
│ 电话：013…（文本）   │
│ 来源：报名文字、截图 │
│ [处理问题] [看详情]  │
└───────────────────┘
```

此为布局示意，数量是合成示例；本例8待补和4冲突为互斥记录，实际问题类别可重叠。候选唯一去向为116通过/12待核/0移出，问题数另计，不把各问题组相加当记录总数。卡片默认3—5关键字段，其余进详情。可选“表格预览”只呈用户选定的少量列，可横向查看，不能以横向大表作为唯一操作路径。分页默认20候选，按需拉取；1000候选不一次渲染全部证据图片。

问题卡需要说明问题、原候选、来源和选择影响。缺失可补充或保留待补；冲突可选某个依据、填写新信息或保留。人工值标为用户补充，与提取事实区分。批量仅用于明确相同规则/语义的范围，显示记录数和例外，不默认全选不同冲突。

点击字段来源进MP11，返回仍在原记录/问题；证据含必要原文或页图位置，不用只有一个自评分数。图像支持放大，文字可读；来源已清理时保留原定位摘要与到期说明，不虚报原件仍存在。

## 领取与规范保存

MP12先显示“结果Excel、空白规范、问题报告”，更多文件列出其余六项及用途。尽力/待补版本明显标记，缺少正式规范不能称完整交付。后端仍生成九文件，不要求手机一次下载ZIP。

文件状态使用能证明的措辞：“已获取文件”“已打开预览”“已保存在小程序缓存”或“已完成导出”。宿主无真实系统保存回执时不伪造成功，只说明已启动对应动作，必要时问用户“是否已能打开文件”，用户确认与系统回执分别记录。失败仍可内嵌查看、续领或获准领取路径，不再次收取处理费。

“保存到我的规范”是可选独立动作，展示名称、列数、版本、保存期限与“仅保存字段和规则，不含本次真实数据”。系统实际清除事实示例/证据/任务引用，命名本身可敏感须隔离。新任务选用保存版本，改模板不回写旧任务。

## 弱网、退出与恢复

| 中断点 | 用户看到的恢复 | 系统约束 |
| --- | --- | --- |
| 上传中退出/切网 | 已接收项保留；其余重试或提示重选 | 不保证后台上传；临时路径失效不造成功 |
| 付款时切后台 | 回来先显示核对状态，可查原订单 | 客户端success不是实付，不新建重复单 |
| 等待分析/整理 | 任务页可离开，回来拉服务端状态 | 后端继续，不依赖永久Socket/前台常驻 |
| 修改规范未提交 | 有已保存草稿提示，无保存的不假装已提交 | 请求幂等，旧版本冲突提示刷新比较 |
| 补问题提交超时 | 显示待核对，可查同一次决定 | 查询原动作，不重复扣轮次或覆盖新版 |
| 导出/打开失败 | 保留结果，重试领取或查看帮助 | 导出不触发重新计算或新收费 |

后台暂停轮询和发起新的上传；回前台刷新身份、能力、订单、任务、规范/结果版本。登录过期重新登录再恢复同一归属。拒绝消息通知仍可从任务列表查询，不写“关闭也一定通知到”。

## 视觉、可达性与反馈

采用系统中文字体、明确主次和有限强调色，信息优先。状态同时有文字/图形，不只红绿区分。交互目标以约48逻辑单位作为设计参考，并按宿主rpx/px/设备密度真机测量；不把不同单位等同。测试大字号、长字段名、窄屏和底部安全区。

按钮在等待时明确“正在检查/提交”，防重复点击但保留可恢复入口。键盘弹起时当前输入、错误信息和提交动作可见；错误在相关字段附近并说明修复方式，不只一闪toast。不能依赖hover、复杂双击、精细拖动或仅滑动手势。

私密预览不放公共分享卡，列表只取必要摘要，卡片图像按需加载/释放，离开清轮询。日志不记录正文、下载签名及登录临时凭据。实际性能预算以真机数据制定，当前不承诺冷启动或每任务秒数。

## 交互验收

关联P07-T24、T30、T33—T40：两种模式无需模板/大屏前置；50字段可编辑、1000候选可分页、缺项和冲突手机可处理；来源定位可回；退出重进不重付；实际文件能取用；大字号/键盘/拒权仍有可理解路径。所有页面当前仅为规格，不是已运行截图或已通过的测试。

## v3.1逐页进入、提交与恢复合同

以下规则用于实现及验收；与B既有版式/组件兼容，没有追加独立图稿。allowed_actions与前端校验同时执行，前端禁用不能替代服务端核权/版本。

### MP01 整理首页

- 进入：未登录可看合成演示；真实添加前登录/必要告知。
- 展示：资料队列、DISCOVER/PROVIDED、用途选填、保存状态。
- 提交守卫：至少一份已接收可读源；PROVIDED允许继续选择规范但正式确认前需明确。
- 异常：检查时先校资料/能力；空资料给禁用原因，切模式不删源。
- 恢复：回四根入口保留服务端已收草稿，正文不写普通缓存日志。

关联需求：P07-F02、P07-F24、P07-F33、P07-F34；B组件：B-C01、B-C02、B-C03、B-C04、B-C06、B-C07、B-C08、B-C19、B-C20、B-C26、B-C31。

### MP02 资料清单

- 进入：本人任务草稿或冻结范围只读查看。
- 展示：文件角色/大小/类型/哈希摘要、逐项状态、排除原因。
- 提交守卫：只有草稿可移除/补入，冻结后显示新范围影响。
- 异常：同名不覆盖，不可读不得静默排除；重试只当前失败项。
- 恢复：临时路径失效重选，已有接收source_id不重传计量。

关联需求：P07-F02、P07-F03、P07-F25、P07-F34；B组件：B-C01、B-C03、B-C04、B-C05、B-C06、B-C19、B-C26、B-C31。

### MP03 规范输入

- 进入：PROVIDED且有本人任务。
- 展示：上传/私有规范/手动字段、主表区域/样例/规则/row_kind。
- 提交守卫：表头/必需含义和粒度明确才使用。
- 异常：无模板可切DISCOVER，样例不变源；多目标表需明确当前主表。
- 恢复：返回保留已存草稿，键盘收起不当确认。

关联需求：P07-F03、P07-F06、P07-F32、P07-F35、P07-F39；B组件：B-C01、B-C03、B-C04、B-C08、B-C11、B-C12、B-C13、B-C19、B-C22、B-C26、B-C32。

### MP04 预检与报价

- 进入：预检完成、范围/主表/必要歧义明确。
- 展示：源/排除/局部建议、模式、原单位价、预算/窗口/交付/退款/数据政策。
- 提交守卫：contract版本一致、quote有效、当前SKU有合法支付或免费许可及可用交付。
- 异常：价格变化再确认；不可售不显示假收银；查到未决原单优先核对。
- 恢复：支付中断回MP16查原单，不自动再点支付。

关联需求：P07-F04、P07-F15、P07-F16、P07-F25、P07-F41；B组件：B-C01、B-C03、B-C04、B-C09、B-C16、B-C19、B-C24、B-C25、B-C26、B-C27、B-C31。

### MP05 处理进度

- 进入：本人已许可任务或其子执行。
- 展示：真实阶段/已读范围、预算、采用/审阅待办、取消与可离开说明。
- 提交守卫：仅服务端allowed_actions可点；运行正常无需强塞主按钮。
- 异常：没有可核百分比不用精确进度；取消需显示可能完成/退款待核。
- 恢复：后台停轮询；前台重取run/operation，服务端继续。

关联需求：P07-F17、P07-F29、P07-F30、P07-F37；B组件：B-C01、B-C03、B-C04、B-C10、B-C16、B-C19、B-C24、B-C26、B-C28。

### MP06 推荐规范

- 进入：全范围草案或带局部标识的预览。
- 展示：row_kind、分组字段/全部9或更多字段、规则依据、范围/未映射、代表预览。
- 提交守卫：FULL且源/目标/提案版本相符才采用。
- 异常：局部采用禁用且解释；调整先预览影响，旧版409保留草稿。
- 恢复：离开回来重取proposal，不能以截图缓存代替当前版本。

关联需求：P07-F29、P07-F30、P07-F31、P07-F35；B组件：B-C01、B-C02、B-C03、B-C04、B-C11、B-C12、B-C15、B-C16、B-C17、B-C19、B-C32。

### MP07 字段编辑

- 进入：本人当前规范草稿/提案可编辑。
- 展示：名称/类型/必填可空/单位/顺序、规则理由、自然语言指令。
- 提交守卫：字段名唯一、规则不矛盾，关键变化已看影响才确认。
- 异常：上移/下移可替代拖拽；非法值内联；不默删列放宽验收。
- 恢复：未提交提示，冲突允许复制草稿/刷新比较，不覆盖新版。

关联需求：P07-F06、P07-F30、P07-F35；B组件：B-C01、B-C03、B-C04、B-C08、B-C12、B-C13、B-C19、B-C25、B-C32。

### MP08 结果概览

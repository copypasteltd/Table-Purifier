## 通用执行约束

用户真实资料处理前须验证身份与告知；只处理已确认范围。所有资源服务端校验归属，写操作带幂等键与适用版本；网络未知先查原动作。执行、规范、质量、交付、付款、退款、设备取用分开。SourceAsset只读、规范/结果版本不可变；平台能力以实证开放。完整规则见[业务规则](需求深化/01-用户故事与业务规则.md)、[数据与状态](需求深化/02-数据字典与状态迁移.md)。

每项下的AC是后续验收条件，全部NOT_RUN；主用例仍按P07-T01—T42索引，参数化情况见[验收计划](05-验收测试与实施计划.md)。P1为F21/F22/F28/F42，不以P1代替普通手机任务。


### P07-F01 身份、任务空间与资料隔离

优先级：P0。作为资料所有者，我要在当前平台找回自己的任务，且别人无法用ID访问。

**范围。** 平台登录映射租户，提交资料/可选规范/说明并选PROVIDED或DISCOVER；执行、规范、内容验收、支付、退款各自有状态。对外API密钥为P1，均可限权撤销。

**触发与输入。** 已核验平台会话、当前账号、资源ID和权限版本。用户主动发起或相应服务端已确认事件触发；系统返回当前版本及允许动作。

**正常流程。** 登录后列本人任务；会话过期先重新验证再恢复原任务，不新建收费单。

**异常与边界。** 跨租户/伪tenant/撤销会话拒绝，错误不透露他人资料。

**验收条件（未执行）。**

- P07-AC01-01：两账号互换任务/证据/规范ID均拒绝。

- P07-AC01-02：会话撤销后下一次访问拒绝。

- P07-AC01-03：退出重登恢复原归属。

追踪：主用例P07-T01；页面MP15；接口P07-API01、P07-API02、P07-API03、P07-API44、P07-API45。

**异常与边界。** 坏文件与密码文件可重选；同名不覆盖；未读项不静默跳过。

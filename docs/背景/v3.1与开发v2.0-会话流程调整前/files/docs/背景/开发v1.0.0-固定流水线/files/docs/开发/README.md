## 适用范围与完成定义

业务 v3.1 的 42 项需求（38 P0 / 4 P1）、126 条验收、24 业务规则、18 非功能要求、8 质量指标、24 异常、18 页和 53 API 继续有效。API38 的跨端绑定为可选 P1，但 F40 的身份隔离属于 P0；API39 为内部 P0。API40—43 为 P1，不能为了文档列齐就对消费者开放。

开发版明确内部实现决定；外部主体/类目、获准 SKU、真实 SDK 字段、最低宿主版本、OCR/模型合同、域名和证书必须由真实证据锁定。24 小时/两轮/7 天、性能和恢复数字仍是候选政策/预算。免费许可也不能绕过隐私、文件交付及事实质量门槛。

开发工件复核结果见[核验报告](../评审/P07-开发文档-v1.0.0-核验-2026-10-27.md)。交接包位于 `output/development/`，包含当前需求、B参照和开发工件；不会带入runtime或真实客户内容。

单个任务完成需代码、真实测试证据、版本和对应需求更新；完整首版需两个平台四环境、质量/资金/删除/恢复与平台发布门槛通过。文档校验通过只说明开发资料可追溯、内部结构一致。

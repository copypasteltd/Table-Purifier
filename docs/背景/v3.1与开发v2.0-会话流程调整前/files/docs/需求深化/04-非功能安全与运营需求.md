# 非功能、安全、质量度量与运营需求

P07｜v3.1｜2026-10-27｜目标与验收口径，非已达成绩。以下性能/时限/恢复数字为试点候选预算，不是对外SLA；W01先固定环境、W11实测确认。授权/事实/资金等阻断原则不因候选性能未定而放松。

## 质量定义与防失真

标准答案由独立人工先标对象、关键字段、事实值、来源与缺失；争议先双人裁定，不用同一生成模型自证。至少30组，DISCOVER≥10、至少两主题，按模式/格式/主题分层报告。不能只报告所有样例的加权均值而隐去某一格式完全失败。

| 指标 | 分子/分母 | 目标 | 注意 |
| --- | --- | --- | --- |
| Q01 字段值准确率 | 正确输出的非空事实字段数/全部输出非空事实字段数，按人工对象对齐和规范等价比较 | ≥98% | 人工值、批准派生/默认单列，不混入模型提取成绩 |
| Q02 记录召回 | 匹配人工答案的有效业务记录数/人工应有记录数 | ≥95% | 同名误合、漏事件都计错；移出难行不能缩分母 |
| Q03 已有事实字段召回 | 正确填出的来源已存在字段数/人工标注来源存在字段数 | 候选目标≥95%，W01冻结 | 防止大量填null抬高准确率；缺失原本无值不入分母 |
| Q04 无模板关键字段覆盖 | 合理规范中覆盖的人工关键字段数/人工关键字段数 | ≥95% | 等价同义可匹配，删稀有重要字段计漏 |
| Q05 证据有效性 | 定位存在且对象/字段语义相符的引用数/全部事实引用数 | 关键字段无未标记严重错误 | 合法坐标不代表语义一定对应；抽样/全查范围说明 |
| Q06 范围账本完整 | 有唯一去向的源单元/已确认源单元；唯一去向候选/总候选 | 均100%账本覆盖 | 只证明账本完整，不证明语义零漏抽 |
| Q07 交付完整性 | 回读校验通过的约定文件数/9；真实取用成功次数/实际取用尝试数 | 9/9；取用目标W01锁定 | 缓存/取消/网络错误分别统计，不虚称全部系统导出 |
| Q08 用户效率 | 同资料人工总用时与辅助任务用时/确认数对照 | 试用后确定改善目标 | 不在没有试用时写效率提升百分比 |

空分母记NOT_APPLICABLE，报告实际数量与原因，不以100%代替。字符串标识精确匹配，金额按批准精度/币种比较，日期按批准时区/粒度；不同对象行不能因值相同算对。多出的错误记录计精度损失，漏记录计召回损失，错合同时记录严重错误。规范覆盖与实际字段提取分别量化。

关键标识/金额/数量/行粒度无未标记严重错误为独立阻断；不能用98%平均准确率掩盖一次关键资金/对象错误。用户补值不能反算为模型自动正确。30组为最小发布集，不具有大样本统计保证，扩量后持续增加边界与回归样例。

## 数据期限与删除执行

所有期限来自已启用retention_policy_id，不在客户端硬编码为不可变商业权益。源/中间、提案/结果/摘录、主动另存规范、必要账务/日志、供应商副本和备份分别列清理范围与实际到期。原件清理后仍有效摘录明确标注，供应商不支持即时清理时如实告知。

删除先登记tombstone及撤销访问，再排对象/数据库字段/缩略/检索缓存/供应商请求清理；重复执行幂等。失败有重试/告警，不把提交删除请求显示为“所有副本已清”。恢复备份先重放删除/撤权再开放访问；用户主动导出的副本不可远程收回。

注销先解释进行中任务、已付履约、退款、私有规范影响；不删除必要账务掩盖售后，也不无限保留正文来充当账务记录。具体法定留存/平台期限在真实主体和合同评审中确定，本文不是已完成的法律评估。

## 运维动作与后台最小范围

P0只需受控内部工具/命令和运营列表，不额外承诺完整商家后台。最小能力：查任务阶段及脱敏计量、未知支付/退款重查、工单授权、停开能力、查看清理失败、按版本回退、备份恢复、发布证据登记。高权限操作分角色、二次确认、有审计；客服不能改事实/收款账户。

告警包括：队列积压/任务计算预算、阶段失败率、原渠道未知款、重复或错金额事件、产物不齐/哈希不符、清理失败、越权/密钥异常、模型费用异常。严重事件暂停受影响新处理/收费，保留原订单查询、售后及必要恢复，复核资金/内容影响后纠正或退款。

成本按quote/contract/run/stage/attempt和供应商版本汇总，包含免费预检、OCR、发现/调整、提取、重试、修订、9文件、流量、支付费/退款及人工客服。实收减退款减可归属变动成本为贡献，不等于净利润；不把平台虚拟单位直接按固定汇率算人民币收入。

## 本机与部署约束

本项目所有文件、依赖、下载、测试与运行内容留在项目路径。仅Windows原生工具和现有可用运行时，不调本地Docker/WSL/虚拟机。解析子进程限制不等于可以安全执行任意附件代码。真正生产部署、安全基线、供应商和监控依赖在实施阶段锁定；目录及文档不是可运行系统。浏览器若使用，结束时关闭本次不用标签；文档网页复核不启动桌面标签页。

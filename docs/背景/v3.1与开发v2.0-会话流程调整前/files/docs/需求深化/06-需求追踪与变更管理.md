## 文档职责与冲突处理

PRD规定目标/范围；功能规格与AC给可观察行为；业务规则/数据状态/引擎规格定义不变量；交易与账号专项约束原渠道事实和可售合同；平台证据决定实际可开放能力；页面规格映射用户动作；B定型控制颜色/字体/组件/视觉层级。适用平台正式规则/契约约束对应发布能力，不能用旧画稿推翻业务语义。

同层文档冲突不能任选：先定位ID、具体触发和影响，再同步当前规范、结构资产及验收；未消除的实际发布依赖关闭相应能力，但其他可独立工作继续。历史快照/旧评估/合成图/静态核验均不作为产品测试或商业开通证据。

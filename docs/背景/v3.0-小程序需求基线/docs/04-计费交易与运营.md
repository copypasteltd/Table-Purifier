# 表格修复站：计费、交易与运营

P07｜v3.0｜2026-10-27｜双小程序消费者交易优先；所有价格、预算、期限为拟定合同，须与获准平台规则和真实成本一致，当前未销售。

## 商品和计价

一单包含一个资料集、规范模式/版本、用途、计算预算及结果合同。DISCOVER包含资料结构分析、规范设计/首次采用、整理及规范交付；没有模板不构成隐藏加价。复杂新增源/用途/规模先展示新范围，不自动扣费。原1.9元/2分钟承诺不延续。

服务端quote含源清单/排除、平台/app/OS资格、商品合同、计价单位/数量、应付显示、费用上限、预计时限、规范采用/修订政策、交付/导出路径、退款/保留政策及版本。默认有效15分钟，平台订单期限按真实通道协调，过期重新核对价格，前端不能传可执行金额。

支付宝现金按整数分记账；若抖音获准方案使用平台计价单位，保存该单位/数量、商品ID、原始交易及平台回传现金结算，不能假定固定换算率/费率或混用余额。报价、面板、订单展示一致，平台佣金/结算期/退款能力以签约实测为准。

预检与有限目标解释免费，可预览最多3单元并标局部；试点每日5个新预检任务/租户，缓存复用不多算。全范围分析/抽取在用户明确启动且获准交易/免费额度确认后执行。不得先无限全量计算再假设一定付费。

## 状态与权益

QUOTE/ORDER/PAYMENT/RUN/RESULT/EXPORT/REFUND分别编号。消费者通常在服务端核实平台付款后放行履约；若获准协议有不同许可/结算时序，适配后保存证据，不自行假定托管或预授权。客户端success只能触发查单，不能记实付/发正式权益。

同订单原生回调重复、网络重试、查询、下载不重复收费。幂等键含tenant＋动作，请求摘要冲突409；原生流水唯一归属平台/app/商户/订单，不能跨小程序重放。回调验签、商品/金额/单位/币种校验、事件入库、事务/发件箱后推进。未知查原单不重收，取消/完成条件更新裁决。

跨端账号绑定不等于付费权益共享，未验证平台规则前只在原渠道领取收费任务。已下载文件无法收回；退款后撤销未来新链接/继续执行权益，保留售后和必要账务访问。累计退款不得超过已确认实付/对应平台单位，退款申请不等于到账。

## 内容验收与修订政策草案

默认STRICT_STANDARD：约定范围处理完成，规范明确/采用、重要信息覆盖和结果规则验收通过。BEST_EFFORT_REPORT只允许购买前用户主动选择完整结构＋已有事实＋问题报告；缺源事实不自动退款，平台漏读/错误/坏报告仍须纠正/退款。两模式都不能在执行后替用户降标准。

首次可审阅工作区起24小时含规范首次采用及两轮用户合并修订，采用前原用途内调整不扣轮次，平台纠错不占轮次；PROVIDED起点为首版结果，DISCOVER为全范围规范草案/预览。服务端计算预算与人工等待分开，不假定支付授权持续24小时。窗口/次数/在线保存只在平台允许且用户事前知情时采用，不能违背平台商品/售后义务；若不适配，先修订可售合同再开通。

STRICT到约定窗口结束仍无可采用规范或无法通过，按获准退款路径退实付；所有政策0候选全退。不得删价格列、放宽必填或丢对象来避免退款。新增源/用途可报价新单，平台漏识别不算新增需求。用户关闭问题卡不等于同意猜值。

## 留存、模板与成本

| 数据 | 拟定策略 |
| --- | --- |
| 未购买源/模板 | 上传24小时清在线内容，草稿只留无正文摘要 |
| 运行源/OCR/中间内容 | 覆盖审阅窗口，窗口结束再留24小时，最迟workspace_ready后48小时 |
| 无工作区的失败/取消源 | 终态后24小时清理 |
| 各版草案/预览/结果/证据 | 各内容版7天，可能含原值，界面明示到期；符合平台交付/售后要求才启用 |
| 主动另存的私有规范 | 剔除真实值/证据/访问引用后独立保存，至用户删除/注销；服务终止等按告知政策处理 |
| 端侧临时图片/缓存 | 尽快清理或失效，不作长期备份；用户主动系统导出副本由用户管理 |
| 交易/日志/备份 | 共用规范，内容删除标记防恢复重暴露，必要账务与正文分离 |

源到期后报告摘录可能仍在7天内，不能宣传已清空所有原信息。在线文件保留期不是限制已下载文件使用时间；售后/交易记录访问及赔付义务不随在线文件删除而消失。私有规范字段名也可能敏感，不自动公开或用于训练。

成本含免费预检、解析/OCR/模型、结构发现及调整、归并/校验/9文件、页图/卡片投影、上传/下载、两轮修订、平台支付费/退款、客服及双端运维。不只计算一次模型推理；按真实实收/退款/变动成本看贡献，贡献不等于净利润。发布前实测价格，不虚报低价、速度、真实用户或流水。

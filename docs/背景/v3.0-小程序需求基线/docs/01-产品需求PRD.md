# 表格修复站：产品需求 PRD

P07｜v3.0｜2026-10-27｜支付宝、抖音小程序优先，Web进阶。状态：需求设计稿，尚未实现软件或开通平台交易。依据用户本轮载体调整更新；[v2.1网页优先基线](背景/v2.1-网页优先/01-产品需求PRD.md)已归档。

视觉设计已选定**B青绿资料夹**，见[设计定型基线P07-DS-B 1.0.0](设计定型/B-青绿资料夹-v1.0.0/README.md)。本次不改变v3.0业务范围及42项需求。

## 产品定位与目标

用户在支付宝或抖音小程序提交零散文本、照片/截图及获支持的文档；有规范按规范整理，无规范由系统分析主题、对象和字段，推荐规范，采用后自动清理归并填表。交付已填数据、可复用空模板、问题与来源依据。

目标是减少阅读、设计表头、复制、合并、核对的时间。最低输入只有资料，规范生成与按规范填表均为首版核心能力。资料里没有的事实不编造；结构合理、规则通过、内容有据分别验收，不能删列/放宽规则制造全通过。

## 载体与发布层级

| 载体 | 优先级 | 用户能力与责任 |
| --- | --- | --- |
| 支付宝小程序 | P0 | 手机内完成导入、规范生成/采用、整理、问题确认、领取/导出、模板复用、订单与售后 |
| 抖音小程序 | P0 | 同一业务闭环；登录、文件、交易、隐私、生命周期按抖音单独适配及验收 |
| Web进阶版 | P1 | 大屏表格/来源并排、批量编辑/比较、复杂字段配置和跨端续作；协作/多表/更大规模按独立版本开放 |
| 自有业务API | P0后端 / P1对外产品 | 小程序复用同一业务规则；开放SDK/MCP及Machine Pay售卖为后续适配，不让普通用户处理HTTP402 |

两端各有原生交互与真实设备验收，不以web-view套网页或一端成功代表双端完成。用户无需先打开Web进阶版才能完成普通任务。可选文件接力/领取页只在平台允许且归属验证后使用，不承担进阶编辑、不承载跨平台支付引导；若不可用，应采用已获准端内路径或明确能力未开放，不能虚报全P0已完成。

## 两种模式与规范

| 模式 | 用户输入 | 系统产出 | 验收基准 |
| --- | --- | --- | --- |
| PROVIDED：我有规范 | 资料＋文件模板、私有规范或手机字段编辑器 | 按目标列/顺序/类型/规则整理 | 用户明确的规范版本＋事实/覆盖检查 |
| DISCOVER：帮我生成规范 | 资料，可选一句用途 | 分析主题/行粒度/候选字段/同义/单位，推荐规范＋预览，采用后整理 | 用户采用的推荐版本＋规范合理性/覆盖/事实检查 |

一行代表人、公司、商品还是一次报价必须明确；多主题先推荐本次主表，其余内容列明。首版一个任务一个主要结果表，不能把一对多对象强行合并。示例行只解释规范，不是来源事实。观察值不自动证明必填/唯一/封闭枚举，低频重要字段不因稀疏而丢弃。

规范推荐卡展示列/解释、类型/单位、建议必填/可空、归并依据、来源与未纳入项。用户一键采用，也可说“增加保修期”“每次报价分一行”或通过字段卡修改。仅关键歧义需询问，正常事实不用逐格批准。采用后形成不可变版本，变更影响先展示，平台漏识别的修复不归入收费新增需求。

## 手机输入与范围

服务端解析计划支持：粘贴文本、TXT/Markdown、CSV/XLSX、DOCX、文字/扫描PDF、JPG/PNG及OCR。文件可解析、宿主能否选择文件、能否上传及能否导出是四种不同能力，分别标注。

端内常用入口为粘贴文字、用户点击拍照/选图、选取已保存规范；普通文档选择入口依据各端已证明能力展示。禁止假设读取任意聊天附件/整个相册/手机目录。不支持的入口显示具体原因及已获准替代方式。普通文档导入和Excel导出是产品目标；某端若无获准且真机验证的路径，该端只能标受限内测，不能宣称P0全能力就绪。

试点上限：10来源文件、单20MB、总50MB，文本5万字符；PDF页/DOCX固定分块/独立图片共50单元；目标50列、1000候选；导入模板另限5MB。DOCX计量规则预检锁定，原页OCR区域不重复计数。这是服务端预算，不代表小程序能在本地缓存50MB或原生一次选10个文件；上传按单文件队列，端侧限制可更小且报价前说明。超限不截断冒充完整，不追加隐藏扣费。

## 小程序主流程与界面

底部四个入口：整理、任务、规范、我的。首页只要求添加资料，规范为可选项。两模式共享流程：添加资料→可读性/范围预检→展示费用与正式开始→分析/理解规范→必要采用/澄清→自动整理→集中处理问题→领取结果。

手机采用记录卡片、字段分组和问题列表；支持表格预览与选列，不要求在50列横向表格内逐格审核。点击记录打开字段详情，点击字段打开来源页/图及证据。问题卡展示候选、来源、影响，允许选择依据、人工补充或保留待确认。重要动作有文字状态，键盘/底部安全区不遮挡操作，触控和系统字号单独验证。

服务端处理可在用户离开小程序后继续。回到任务页从服务端恢复执行/支付/规范/结果版本，不依赖手机持续运行、永久Socket或后台上传。上传未完成且临时文件失效时提示重选，不假称已入库；授权通知为可选能力，拒绝不影响主动查任务。

## 结果与私有规范复用

手机优先呈现“结果Excel”“空白规范”“问题报告”，其他机读文件放更多选项；内嵌卡片/表格预览由自有数据渲染，不依赖宿主是否能原生打开XLSX。文件下载、宿主打开、保存到小程序缓存、用户导出到可访问位置分别记录，不能把缓存成功说成已存到手机可见文件。

后端固定9文件：standard.xlsx、standard.json、result.xlsx、accepted.csv、result.json、issues.xlsx、provenance.jsonl、validation.json、manifest.json。manifest校验其他8文件，自身哈希另由接口给出；空集保留结构。未采用规范仅草案，不是正式通过；可导出待补充版本需准确标记。

用户可主动“保存到我的规范”，得到脱离来源值/证据/访问引用的私有模板版本，后续两种任务均可选用。模板库保存规则和授权独立于原始资料，默认不公开分享；字段名称本身也可能敏感，仍须租户隔离。

## 账号、交易、数据与成本

平台身份按provider＋app_id＋subject映射私有账户；昵称/相同手机号/不同平台openid不用于自动合并。首版不强制跨平台绑定，不强制手机号；后续绑定需两边分别验证。订单、退款、权益保留原平台，未验证规则前不承诺跨平台付费权益通用。

支付宝、抖音分别按实际获准的类目/商户/交易系统接入，iOS/Android收费资格分别判断。Machine Pay不再作为消费者P0默认收银台，普通小程序支付也不自动等于赛事AI付认可。抖音官方iOS页面存在限制与新虚拟支付说明并列，具体商品资格、能力和规则冲突需正式确认，未确认单元不收费、不外跳绕行。

按源集/模式/用途/计算预算报价，DISCOVER含规范生成和首次采用；总价/平台计价单位/费用上限与面板一致，重试/下载/查询不重复收费。默认严格规范验收，可在购买前主动选择尽力报告；0候选全退、平台失败纠正/退款。24小时工作区与两轮修订为拟定服务政策，需通过各平台商品/履约合同验证，不能假定支付授权持续24小时或绕过平台售后义务。

未购买源内容上传24小时清理；运行源/中间内容覆盖审阅窗口，最迟首次可审阅工作区后48小时清理；无工作区失败/取消终态后24小时。各版草案/预览/结果/证据7天。用户主动另存的无来源值私有规范按单独政策保存至删除/注销；到期在线保存与已下载文件使用、售后权益分开。用途/OCR及模型处理方/地域在处理前告知，不默认用于平台训练/公开；第三方条件按实际合同，不承诺未知的零留存。

## 验收、实施与文档导航

共42项功能：38项P0、4项P1，验收均待执行。至少30组合成/授权人工标准答案，含至少10组无模板、两种以上主题和跨源样例。拟定字段准确率≥98%、记录召回≥95%、无模板关键字段覆盖≥95%，关键标识/金额/数量及行粒度无未标记错误；这是发布目标，未测不能宣传已达到。

双端×iOS/Android逐项验证登录/隐私、文本/图像/文档路径、规范采用、移动审阅、弱网/离开恢复、支付/退款及真实导出。不能通过单端模拟器、只测后端或只生成文档认定小程序上线完成。双端完整范围需按新实施计划重估，原网页4–5周不再有效。

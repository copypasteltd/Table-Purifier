# 表格修复站：验收测试与实施计划

P07｜v3.0｜2026-10-27｜双小程序优先，Web进阶。以下均为待执行计划，文档核验不等于软件、支付、审核或内容质量已通过。

## 标准素材、质量与交付

至少30组人工先标答案的合成/授权任务，覆盖报名/联系人、采购/报价等至少两种主题；PROVIDED/DISCOVER两模式均测，无模板不少于10组。每组记录用途、行粒度、应有对象/关键字段、合理规范范围、来源定位、缺项/冲突、拆合和预期状态。标准答案由独立人工先标，不用同一模型输出自证正确。

包括纯文本、TXT/Markdown、CSV、多表XLSX、DOCX正文/表格、文字/扫描PDF和截图混合；同名异人、一文多人、模板样例隔离、低频重要字段、漏页/无关段落、OCR歧义、前导零/长ID、相对日期、精确金额/单位/币种/粒度、指令注入/坏文件/宏公式与超限。实际手机选择路径与服务端解析集分别验证。

目标字段准确率≥98%、记录召回≥95%、无模板关键字段覆盖≥95%；关键标识/数量/金额及行粒度无未标记错误。按格式/模式报告分子分母、严重错误和局限。候选守恒不代表语义召回，自己生成规范的符合率不代表内容完整。未达标需缩小支持范围并重测，不能提前对外宣传。

九文件校验、三主文件手机真实取用、两种规范来源和证据、支付/退款、隐私/清理各有独立证据。当前均未运行。

## 开发顺序与估算

[开发任务与里程碑](实施/小程序优先开发任务与里程碑.md)分12个工作包，初估85—118人日；按2名全职熟悉相关技术的开发者，纯人日折算约8.5—11.8周，计顺序依赖和联调计划约10—14周。外部主体/类目/商户/平台审核等待、无法预见的供应商变化不含在内。此为估算，阶段验证后重估；原网页4—5周已不适用。

可以先做15—25人日受限演示：合成样例、两个规范模式、一个已证明输入/导出路径、原生页面及明确沙箱/免费状态。演示不等于双端全范围P0，不能把缺少格式、iOS交易或质量验证写成已完成。Web进阶单独排期。

## 迁移和阻断缺陷

检查活动文档和页面不残留：网页作为首版唯一主载体、强制模板、仅CSV/XLSX输入、订单固定六列、固定1.9元/2分钟、仅5条样本冒充全量、输入行等于输出行、仅7文件、消费者手工402、缓存等于导出、普通订单等于赛事AI付等旧承诺。历史快照可保留且必须标历史。

越权、未标记捏造、错归并、漏源却称完成、金额/标识/粒度严重错误、重复收退及隐私泄露为阻断缺陷。暂停受影响新单，保留原订单查询/售后，定位、纠正或退款并复验后再开放。在线文件到期不免除售后责任。

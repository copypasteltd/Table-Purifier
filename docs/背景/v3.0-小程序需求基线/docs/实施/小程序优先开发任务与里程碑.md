## 里程碑与决策

| 里程碑 | 核心证据 | 决策 |
| --- | --- | --- |
| M0 可行性 | 四环境普通文件/规范入口、真实Excel取用；主体/类目/交易尤其iOS适用规则 | 若无路径，明确受限内测/改入口或商品；不能硬写全能力 |
| M1 数据合同与黄金样例 | 30组初稿、两主题/两模式、版本/来源/规范/报价合同 | 冻结首轮支持范围与平台适配约定 |
| M2 引擎纵向链路 | 合成资料→推荐或已有规范→采用→整理→独立验收→九文件 | 先保证事实/粒度/覆盖，不用漂亮页面代替结果 |
| M3 双端业务闭环 | 两端手机输入、规范、问题、恢复、真实取用；未开通端明确免费/受限 | 普通任务不用Web进阶版 |
| M4 交易与质量 | 获准通道支付/退款、实际文件、30组质量、四环境严重缺陷清零 | 通过G01—G10才提审/灰度，不拿mock算完成 |
| M5 受控发布 | 平台审核事实、域名/隐私/售后、清理/对账/告警/回退 | 按已批准端/OS开放，逐步放量 |

规范引擎和手机端可由两位开发者按稳定合同交错开发，平台差异先做小规模试验；这里是人员工作划分建议，不调度额外代理或虚拟环境。支付宝链路可先贯通再复用到抖音，但抖音仍是P0，有单独验收和发布资格。

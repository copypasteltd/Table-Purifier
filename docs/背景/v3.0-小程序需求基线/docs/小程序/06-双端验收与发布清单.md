## 内容质量与性能

发布目标：支持范围字段准确率≥98%、记录召回≥95%、无模板关键字段覆盖≥95%；关键标识/数量/金额及粒度无未标记错误。按格式/场景/模式分别报告分子分母和错误类型，多源归并、低频字段、同名异人、OCR歧义、单位金额等必须覆盖。独立人工先标答案，不能让同一模型自己判全对。

同时记录端内可交互时间、列表/证据加载、上传成功率/恢复、任务p50/p95、分段时长/成本、人工确认数、导出成功率和退款一致性。当前均无实测值，不填写虚构性能分数。计算预算15分钟为试点上限，不是用户每任务15分钟必完成的保证。

## 提审、灰度和回退

提审包说明真实功能/输入范围、隐私、价格、交付/售后和客服，不展示未支持入口；必要审核账户/资料为合成且受控。支付宝和抖音独立提审，各平台审核外部时长不算研发完成。

先获准端/OS小范围免费或正式内测，按真实权限开放收费。放量前完成严重缺陷关闭、成本验证、日志告警、未知订单对账、数据清理和回退演练。发现越权、金额/标识/粒度严重错误、漏源仍宣称完成或重复收退，暂停相关新单，保留已有任务查询/售后及必要恢复。

回退不覆盖历史规范/结果/账务，模型/解析版本可定位。能力开关按平台/OS/构建控制，受限原因可见；修改规则后重新跑受影响场景，不能只改文案宣布问题已解决。

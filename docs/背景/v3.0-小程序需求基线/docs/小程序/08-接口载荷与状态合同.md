# 表格修复站：小程序接口载荷与状态合同

P07｜v3.0｜2026-10-27｜自有API草案，未实现。本文字段均不是支付宝/抖音官方SDK签名，平台登录/支付参数需正式适配器核验。[架构主文档](../03-架构数据与接口.md)给出实体和接口总表。

## 通用约定

API前缀/v1/p07，服务端根据会话确定tenant/身份，客户端不能指定他人主体。时间统一UTC ISO8601，界面本地化；ID为不透明字符串。写入含Idempotency-Key，带当前版本的操作另含expected_*_version。同键不同请求409，同键同请求返回原资源及处理状态。

金额/平台单位用整数，精确字段数值用十进制字符串，标识始终文本；空缺用null及明确status，不用0或空字符串冒充未知。分页默认20、上限100，实际图片按需拉取；过滤前后计数分别返回。服务端错误不返回内部文件路径、正文或凭据。

以下ID均为合成占位。运行层schema_version与产品需求v3.0分别演进，不把需求版本自动套成所有JSON版本。

## 创建任务与提交来源

```json
{
  "mode": "DISCOVER",
  "goal": "按每次商品报价整理，便于比较",
  "source_channel": "douyin",
  "selected_private_template_version_id": null
}
```

POST /tasks创建DRAFT，mode=DISCOVER不要求standard_id；若选私有规范应明确切为PROVIDED并绑定版本。GET /tasks?cursor和GET /tasks/{id}供任务列表与恢复，返回服务端状态/版本/期限、待办入口和可执行动作，不返回全部正文。

POST /tasks/{id}/sources支持文本JSON或单文件multipart，角色SOURCE；POST /tasks/{id}/standard接受目标模板/字段定义/私有版本，角色TARGET_TEMPLATE。接口按content-type区分，不能将上传规范自动添为源事实。文件完成后服务端计算sha256并核真实类型/大小，客户端摘要只是去重提示。GET /tasks/{id}/sources返回每来源上传/解析/排除状态。

```json
{
  "source_id": "src_demo_01",
  "role": "SOURCE",
  "name": "报价示例.pdf",
  "status": "RECEIVED",
  "parse_status": "PENDING",
  "bytes": 12500,
  "sha256": "<服务端真实摘要>",
  "source_set_version": 2,
  "expires_at": "<服务端时间>"
}
```

RECEIVED只说明接收，不等于已读所有页。临时路径不会直接保存为服务器下载地址。不支持客户端任意url抓取。资料删除/角色变更用受控动作并校验源版本，已冻结范围不能静默改变。

## 预检、冻结与报价

POST /preflight返回可读性、文件/字节/单元计量、unsupported/failed/excluded及理由；有限语义建议含scope=PARTIAL和具体单元，不宣称全部分析。没有可读来源返回可理解补充动作，不创建收费执行。

POST /confirmations固定source_set_version、mode、goal_version、明确排除、验收政策及数据处理同意版本。PROVIDED另固定schema_version；DISCOVER固定规范设计/采用过程的合同，最终采用另追加绑定。POST /quotes基于此生成价格/单位/上限、有效期、交付路径及政策版本。

```json
{
  "confirmation_id": "confirm_demo",
  "source_set_version": 3,
  "mode": "DISCOVER",
  "goal_version": 1,
  "standard_binding_id": null,
  "acceptance_policy": "STRICT_STANDARD",
  "budget": {"processing_units": 50, "target_fields": 50, "candidate_records": 1000},
  "policy_versions": {"privacy": "<已告知版本>", "service": "<获准商品合同>"}
}
```

预算是上限，不是一定全部用完的额度；PDF页/DOCX固定分块/独立图片的计量规则和结果在预检锁定，原页OCR不重计。10文件/20MB单/50MB总和5MB规范按十进制MB；宿主更低限制单独返回。

## 订单、执行与未知状态

POST /orders仅接quote_id/quote_version及同意记录，服务端核平台/app/商品/OS资格及有效期；POST /orders/{id}/checkout回对应平台适配器收银指令。前端不能自设金额/虚拟单位数量。GET /orders/{id}给服务端确认的payment/refund/fulfillment，不把宿主回调当钱到账。

POST /tasks/{id}/runs基于已确认付款或明确免费许可创建执行，重试返回同run。消费者端无HTTP402签名操作。GET /runs/{id}可包含：

```json
{
  "run_id": "run_demo",
  "execution_status": "WAITING_SCHEMA",
  "stage": "SCHEMA_REVIEW",
  "schema_status": "FULL_DRAFT",
  "quality_status": "NEEDS_REVIEW",
  "payment_status": "<服务端确认的原渠道状态>",
  "refund_status": "NONE",
  "source_set_version": 3,
  "proposal_version": 2,
  "schema_binding_id": null,
  "result_version": null,
  "workspace_ready_at": "<全范围草案与预览就绪时间>",
  "review_expires_at": "<按获准合同计算>",
  "allowed_actions": ["VIEW_PROPOSAL", "REVISE_PROPOSAL", "ADOPT_SCHEMA"],
  "notification_opt_in": false
}
```

这不是状态全组合示例；payment占位必须由真实原渠道映射，不展示技术英文给普通用户。前台onShow重取会话、能力、订单、run；onHide关闭轮询和停止发起新上传，后台处理由服务端继续。超时不自动重复付款/创建执行。

## 规范提案与采用

GET /runs/{id}/schema-proposal返回proposal_version、scope/source_set/goal、row_kind、field_suggestions、coverage和unmapped_important_information。每字段至少有field_id/label/type/nullable、建议规则和理由/证据，观察比例带分母。字段建议不可凭模型自评分变成已采用事实。

POST /schema-proposal/revisions接expected_proposal_version和明确修改或instruction，先形成变更预览；行粒度/删列/必填/单位/归并变化显示影响。POST /schema-adoptions明确采用版本：

```json
{
  "expected_proposal_version": 2,
  "source_set_version": 3,
  "goal_version": 1,
  "action": "ADOPT_PROPOSAL"
}
```

服务端核范围与版本后生成不可变schema_version/binding_id，旧草案409。未采用不能PASSED；冻结后变更追加版本/影响和许可，不能静默放宽验收。规范合理性/关键字段覆盖独立于数据符合率。

## 记录、决定与复验

GET /runs/{id}/records?cursor&status&fields返回候选唯一去向、关键字段、result_version和下一游标。字段值含value、type、status、evidence_ids、rule_version；原值/转换/人工/派生明确。GET /issues和GET /evidence/{id}按当前归属/到期提供候选/来源，证据不暴露文件系统路径。

```json
{
  "expected_result_version": 4,
  "decisions": [{
    "issue_id": "issue_demo",
    "record_id": "record_demo",
    "field_id": "delivery_days",
    "action": "CHOOSE_EVIDENCE",
    "selected_evidence_id": "evidence_demo"
  }],
  "scope": {"record_ids": ["record_demo"]}
}
```

允许CHOOSE_EVIDENCE/USER_VALUE/KEEP_UNRESOLVED等明确动作；人工值单独来源，保留缺失不等于同意猜定。批量范围必须列明或有冻结筛选摘要及数量，例外不能隐藏。提交决定与POST /revisions复验有幂等关联，网络重试不重复扣轮次；平台纠错不扣用户轮次。

## 结果、领取与私有规范

GET /runs/{id}/artifacts返回固定9项的artifact_id/name/bytes/hash/version/expires，空集仍有schema。POST /artifacts/{id}/download-link先校权益，默认5分钟签链；manifest自身hash在接口外层，文件内列其他8项hash。

POST /artifacts/{id}/export-attempts记录observed_action、provider/OS、host版本及receipt_source=CLIENT_OBSERVATION/USER_CONFIRMATION/PLATFORM_RECEIPT，缺平台回执不伪造PLATFORM_CONFIRMED。失败/未知不重跑计费。

POST /private-templates须用户明确保存，用schema_binding_id生成去事实/证据/访问引用的规则快照，不直接长期留整个结果JSON。GET /private-templates、GET /private-templates/{id}、POST /private-templates/{id}/versions、DELETE /private-templates/{id}分别列表/详情/新版本/删除；版本不可覆盖旧任务。跨端绑定/接力接口只有适用规则和双向证明可用后登记开放。

## 错误合同

| HTTP / error_code | 含义 | 客户端动作 |
| --- | --- | --- |
| 401 SESSION_EXPIRED | 会话失效 | 重新登录，再查原任务，不重建订单 |
| 403 CAPABILITY_UNAVAILABLE | 当前发布单元/商品未开放 | 显示原因及允许路径，不外跳收款 |
| 403 RESOURCE_FORBIDDEN | 非本人/无权益 | 不泄露资源详情 |
| 409 VERSION_CONFLICT | 当前提案/结果已变化 | 刷新比较，保留未提交草稿 |
| 409 IDEMPOTENCY_CONFLICT | 同键请求内容不一致 | 停止重放，查原动作 |
| 410 CONTENT_EXPIRED | 源或结果已到期 | 说明类别/到期，仍可查必要订单/售后 |
| 413 SOURCE_LIMIT_EXCEEDED | 文件/文本超限 | 报价前说明，不截断后称成功 |
| 422 UNREADABLE_SOURCE / SCHEMA_REQUIRED | 不可读，或PROVIDED尚未明确规范 | 修输入；DISCOVER不能因没有模板返回SCHEMA_REQUIRED |
| 422 BUDGET_EXCEEDED | 处理中发现超约定范围 | 停止新增开销，按合同说明范围/退款，不自动加价 |
| 202 PAYMENT_PENDING | 查单尚未确定，非失败 | 查原单，UI显示核对中 |
| 429 RATE_LIMITED | 免费预检/接口频次上限 | 明确稍后/剩余额度，不静默付费 |
| 503 DEPENDENCY_UNAVAILABLE | 宿主/OCR/模型等暂不可用 | 可恢复重试；不无限重跑/重付 |

统一错误含request_id、error_code、user_message、retryable和当前资源状态，不含堆栈正文。示例HTTP状态按自有合同设计，实施时平台回调/SDK错误另映射，不能拿自有字段冒充平台API。

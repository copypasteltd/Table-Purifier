# 表格修复站

项目编号P07｜当前需求基线v3.1｜2026-10-27｜状态：需求已系统深化并关联B定型，软件尚未实现，平台能力/支付/真机验收均待执行。

优先交付**支付宝小程序、抖音小程序**；Web是P1进阶工作台。用户提交零散文字、照片/截图及获支持文件：有规范按规范整理；无规范则由系统分析、推荐规范，采用后自动清理归并成表。手机用记录卡/问题列表处理缺项和冲突，领取结果、空白规范及问题报告，可主动保存私有规范复用。

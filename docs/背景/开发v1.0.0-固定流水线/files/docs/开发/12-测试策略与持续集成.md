# 测试策略与持续集成

P07-DEV 1.0.0｜业务 v3.1｜当前产品测试全部 NOT_RUN；文档检查单列。

## 测试分层

| 层 | 工具/环境 | 必须证明 |
| --- | --- | --- |
| 静态/合同 | TypeScript、JSON Schema、OpenAPI 检查、文档 checker | 枚举/引用/路由/类型一致、未泄露秘密 |
| 纯单元 | Node test runner、Python unittest | 精确数值、码点/坐标、规则 AST、清洗/分页/状态 guard |
| API 合约 | Fastify inject + fixtures | 鉴权、owner/字段、错误、幂等、版本、响应 schema |
| 数据集成 | Windows 原生隔离 PostgreSQL 18 | 唯一/FK/事务/租约/RLS/预算/轮次真的生效 |
| 引擎格式 | 合成真实文件/独立回读 | 全范围/不截断、公式/编码/页图、9文件一致 |
| 故障注入 | 进程终止/重复事件/短断网/时钟与租约 | 重放、fence、未知外部款、取消/发布/删除竞态 |
| 内容质量 | ≥30组独立人工答案，DISCOVER≥10、≥2主题 | Q01—08 分层统计和关键严重错误阻断 |
| 双端端到端 | 两平台×两OS、真实宿主/SDK/文件 | 手机两模式、审核、恢复/取用、B与无障碍 |
| 交易/隐私/运维 | 获准沙箱/正式测试通道和恢复库 | 支付退款/对账、删除/备份、开关/回退 |

不为低影响文案逐字镜像写测试；优先验证资金、事实、并发、权限、格式和真实用户路径。数据库测试不能用 SQLite/内存 mock 替代 PostgreSQL 锁/约束；禁 Testcontainers/Docker/WSL。已有环境不可用则明确 NOT_RUN，不伪通过。

## 黄金集与独立答案

每样本含原始合成/获授权文件、预期对象/事件、已有事实值/单位、应缺失项、证据 locator、关键规范字段、允许等价表达、必要问题及排除理由。答案先由独立人工标注并裁定争议，再运行引擎；不能让同一模型生成答案和评分。

至少包含报价、报名/名单等两主题；多源拆合、同名不同人、重复事件、稀有保修字段、待议价格、日期/单位歧义、低清/OCR错字、模板示例污染、不可读/超限、0候选、1000候选及50字段。30组只是最小发布集，报告各模式/格式/主题的样本量与失败，不用加权平均掩盖某格式完全不可用。

Q01 非空事实精度≥98%、Q02记录召回≥95%、Q03已有字段召回候选≥95%、Q04关键规范覆盖≥95%；Q05证据语义/定位、Q06唯一去向100%、Q07九文件9/9和真实取用、Q08用户效率按需求定义。0/false/前导零/decimal/时区比较固定，空分母 N/A。人工值/派生/默认单列，不能提高自动抽取分数。

## 高价值故障与安全用例

- 100次并发同幂等键只建一单/一批次/一预留；同键不同载荷409；旧版本不覆盖。
- 两 worker 租约交替、旧进程晚回、检查点后崩溃、累计预算跨重试/子Run不重置。
- 决定预览过期/范围变化、发布成功只消费一轮、失败释放、免费平台纠错不扣。
- 取消/删除/publish 同时竞争；撤权后新 GET/Range/签链拒绝；已导出限制如实说明。
- 回调重复/乱序/金额单位错、关闭后晚支付、未知退款重查原单、已付无job补偿。
- ZIP/XML/超像素/路径穿越/畸形PDF/不可信公式/提示注入；不运行附件代码、不抓任意URL。
- 甲乙互换所有 task/source/binding/run/record/evidence/artifact/order/template/operation ID；客服无授权/到期拒绝。
- 产物第9文件失败、hash不符、关键字段漏/错对象、EXCLUDED假抬分、模板带真实秘密。

已有 126AC、24异常 E、18NFR 和 G01—10 发布门槛作为 test case 链接，见[需求追踪](../需求深化/06-需求追踪与变更管理.md)。不能把单元mock通过写成四环境/支付PASS。

[机器测试计划](../../assets/development/v1.0.0/test-plan.json)列出126条AC、24异常、18NFR、8指标与20项工程边界；所有执行状态NOT_RUN。四环境另作参数矩阵，30组人工答案尚未准备，不用计划条目充现成样本。

## CI 流水线合同

1. workspace/AGENTS 合规、秘密扫描、依赖 lock/许可证、需求/设计/开发工件 hash与引用。
2. 类型/格式/schema/生成差异检查；shared 不得 import my/tt/Node，两个宿主包不得混另一端适配器。
3. Node/Python 单元、Fastify 合约、合成文件解析/产物回读。
4. 独占隔离数据库的 migration/并发/故障/RLS 集成；DB 名和 runtime 路径白名单，清理前验证绝对路径不超项目。不得“drop 任意连接配置库”。
5. 双端构建、SDK与依赖/配置SBOM、B token hash、P1/未准开关关闭断言；禁止把秘密编入手机。
6. 人工/真实通道和真机门槛从证据登记导入，不在普通CI自动伪造。发布 job 核查证据适用 build/app/OS/SKU。
7. 生成不可变 release manifest/hash/测试报告与差异；有阻断则停止发布，保留原售后运行。

Windows 原生 runner 进程运行即可；不提供容器 CI 作为默认依赖。安装/构建缓存放 runtime，真实资料和商户证据不上传公共CI。每次只跑变更相关及必须检查，已通过且无新变更不重复整套昂贵测试。

## 报告格式与可信度

每结果含 case_id/req_ids/build/config/model/parser/rule/SDK、环境/设备/输入 hash、实际步骤、actual/expected、PASS/FAIL/NOT_RUN/N/A、证据路径、执行人和时间。静态文档报告固定 scope=DOCUMENT_STATIC_ONLY；测试计划条目存在不等于执行过。

性能先固定硬件/网络/10并发候选负载、源大小/单元/候选/字段/图像；报告 p50/p95/失败率/内存/费用。轻GET候选p95≤1.5秒、RPO≤1小时/RTO≤4小时经实测锁定，不能把热缓存数当端到端SLA。B 静态对比度之外，触控/读屏/大字/键盘需真机。

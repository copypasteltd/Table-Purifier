# 表格修复站：功能需求与用户流程

> 历史基线v1.0：2026-10-27已由“多源资料按规范表自动成表”的v2.0替代，仅作历史记录。当前需求见 [PRD](../../01-产品需求PRD.md)。

P07｜v1.0｜状态均为“设计”。流程：上传预检 → 选表与目标模板 → 诊断 → 确认映射/格式/待确认策略 → 确定报价 → Machine Pay → 规则执行与校验 → 交付 → 真实导入反馈。网页和 Agent 使用同一业务服务。

### P07-F01 租户、密钥与工作台

优先级：P0。登录用户管理本人上传和任务；租户管理员创建可撤销、有权限范围的 API 密钥，密钥只展示一次；工作台显示待确认/待付款/处理/交付/退款状态。付款人和租户关系由支付授权明确绑定。

验收：撤销密钥后不能继续调用；跨租户任何文件/规则/任务 ID 都不能访问；服务端不能接受客户端伪造 tenant_id。

### P07-F02 文件准入与安全解析

优先级：P0。支持 UTF-8 CSV、XLSX 值表，限 5 MB/20 列/1–1,000 条非空数据记录。CSV 引号、多行单元格按逻辑记录处理；XLSX 同时检查公式存在，不仅读缓存。拒绝无数据空表、宏、加密、损坏、压缩炸弹、外部链接依赖、公式、合并表头等不支持结构。

验收：合格边界文件准入，空表和超限在付费前拒绝且不收费；公式带缓存仍拒绝；解析不执行链接或宏、不向外部发请求；空行位置有报告。

### P07-F03 选表、表头与目标模板

优先级：P0。用户选择一个工作表和一个表头行；模板定义目标字段、类型、必填、金额/数量精度、币种和目标系统说明。重复列名用稳定 column_id 区分；源坐标保留原工作表行列，不因删空行而错位。

验收：两列同名仍能明确映射，选错表头可在付款前重选；目标模板修改产生新版本，旧任务不变。

### P07-F04 免费诊断与预估去向

优先级：P0。展示行数、列类型候选、缺失、歧义、重复候选和可处理范围；不提前提供完整付费输出。规则选择后提供预计 importable/pending/excluded 数量。初始每租户每日 10 个新诊断，结合文件哈希缓存与突发限流。

验收：诊断明确“可确定”和“需确认”，问题不能被成功比例掩盖；限额提示透明且不自动收费。

### P07-F05 AI 映射建议与最小样本

优先级：P0。只提交列名和最多 5 条必要脱敏样本；订单号/身份字段默认遮蔽。模型建议映射、格式候选和解释，不直接写原表；低置信度需用户确认，模型不可用允许手工配置。

验收：提示注入不执行；日志/模型请求无完整表格；错误建议未经确认不参与批处理；用户能看到发送范围说明。

### P07-F06 规则确认与版本冻结

优先级：P0。用户明确映射、日期地域/格式、金额分隔符/精度、币种来源、重复判定键及待确认策略，形成 mapping_version/rules_version。Agent 必须提交已确认配置，不能依赖隐含交互。预检有数据歧义时可全部进入 pending，不强迫猜测。

验收：配置改动后旧报价失效，新任务有新哈希；未确认必需配置返回 NEEDS_CONFIRMATION 且不收费。

### P07-F07 确定性转换与缺失处理

优先级：P0。执行明确的空格/全半角/大小写规则时记录变更；文本字段是否 trim 由模板指定，订单号默认不隐式删字符。缺失必填值进入 pending，非必填空值保留；不补造商品、日期或金额。

验收：相同源值、配置和规则引擎版本产生相同规范值；未知内容保持或单列，不为凑齐字段编造值。

### P07-F08 订单编号与长数字保护

优先级：P0。订单编号按文本存储和输出，保留前导零及完整字符串；源文件已变成浮点/科学计数而无法确定原值时标潜在损失，要求原始导出，不能推测恢复。

验收：000123 和 20 位文本 ID 保持一致；已截断数值不补位；XLSX 输出单元格明确为文本类型。

### P07-F09 日期、时区与歧义

优先级：P0。显式格式可转换为目标 YYYY-MM-DD；歧义日期按确认的 DMY/MDY 规则，否则 pending。XLSX 日期序列按工作簿日期系统解析；不支持/异常日期单列。时间戳需明确源时区和目标规则，首版模板可只接受日期而将不明确时间戳列入待确认。

验收：03/04/2026 未确认不猜；不同日期系统样例正确；非法日期、跨时区日期变化有记录，不悄悄截时。

### P07-F10 金额、数量和币种

优先级：P0。使用 Decimal/等效定点表示；按显式小数点、千分位、币种和目标精度解析，不以二进制浮点累加。超精度默认 pending，用户明确舍入规则后才转换并记账；缺失币种不从语言猜测。数量精度由模板确定。

验收：人民币与美元不混加；1,280 在分隔规则未确认时不猜；0.10＋0.20 精确为 0.30；单位/实付/标价不同语义分开汇总。

### P07-F11 重复候选与明确移出

优先级：P0。相同订单号默认仅标记，不删行；用户可确认订单号＋商品项等业务键，或明确选择某些行移出。被移出记录进入 excluded 并保留理由和确认人。

验收：同一订单两件商品仍保留两行；整行相同也不在未授权时删除；不存在隐含“第一行赢”的规则。

### P07-F12 记录分类与守恒校验

优先级：P0。每条非空输入记录恰属 importable、pending、excluded 之一；一行可有多个问题，但只能一个最终去向。整行尚有未解决必填问题即进入 pending，不同时复制到 importable。校验输入数＝三类之和，源记录 ID 无重复无缺失。

验收：包含多问题、空白行、明确排除的混合表仍满足守恒；不通过时不发布可领取的成功包。

### P07-F13 变更审计和复现

优先级：P0。记录 source_record_id、源文件哈希、工作表/逻辑行/列、原值/类型、新值/类型、rule_id/version、理由、确认版本；输出转义独立记录。复现以规范结果为准，XLSX 压缩包时间戳不要求逐字节相同。

验收：任意输出值可定位来源和规则；无变更值不伪造改动；同版本重跑规范业务值与分类相同。

### P07-F14 导出、公式防护与报告

优先级：P0。XLSX 文本用字符串单元格写入；CSV 对可能被表格软件当公式的文本采取安全转义，报告说明可能改变目标导入字面值，并提供 XLSX/JSON 选项；不能只靠引号声称安全。导出报告列币种/单位/业务字段分组的金额总计和未解析数量。

验收：含 =、+、-、@ 或控制前缀的危险文本打开不执行公式；正常已解析负数仍为规范数值；安全转义有审计；坏文件/缺报告不能交付。

### P07-F15 报价与购买范围

优先级：P0。固定上限规格 190 分 CNY/任务，报价有效 15 分钟，绑定源指纹、选表、模板、映射、规则与结果预估；结算前说明存在 pending 的部分可导入结果。改文件/配置新报价，不用旧凭证套用。

验收：不支持输入不报价；预计 20 条 pending 明确告知；价格篡改、报价过期和哈希不匹配被拒。

### P07-F16 Machine Pay 授权、验付与结算

优先级：P0。真实接入官方 402 链路；未付款返回实际 SDK 生成的付款要求，授权/验付后按合同执行，结算确认后发放权益。自有状态与官方交易引用关联，禁止自造凭证或用普通网页收款冒充 Machine Pay。

验收：真实获准 SDK 的授权、验付、结算、失败路径均有记录；重复凭证与请求不重复计费，跨任务/租户/金额凭证拒绝。

### P07-F17 持久执行与重复请求

优先级：P0。幂等键按租户＋动作绑定输入摘要；同键同请求返回原 job，同键不同请求冲突。任务最多初始执行加 1 次平台重试；可履约后 2 分钟未完成进入明确失败处置。重试/轮询原任务均免费。

验收：重启/并发重复只产生一个可交付任务；平台重试不新建付费单；超过上限可定位并退款或释放未结算授权。

### P07-F18 结果领取与机器可读状态

优先级：P0。返回状态、三类行数、问题码、规则版本、报告链接和到期时间；结果保留 7 天，签名下载 5 分钟有效。Agent 不依赖网页文本解析；可选择签名通知，但轮询为可靠基线。

验收：重复下载不收费，过期/退款/跨租户不能获新链接；未知任务不泄漏他人存在；partial 表示有 pending，不表示系统执行失败。

### P07-F19 取消、失败、退款与纠错

优先级：P0。未执行可取消；执行中不保证立刻终止，查最终状态。平台不能交付冻结合同则有限重试后退实付或释放未结算授权；用户事先知情的 pending 不算平台失败。若规则程序错误导致错误交付，免费重做或退款。

验收：重复售后不超额退；授权未结算不能伪记退款到账；冻结合同中的问题范围与最终交付不符触发复核。

### P07-F20 清理、运营与指标

优先级：P0。原始表与中间正文按 24 小时政策清理，结果 7 天；运营看脱敏任务和转换错误，可暂停规则版本，客服内容访问留痕。记录去重付费、真实导入反馈、成本、退款、问题分布。

验收：到期后在线原表不可访问；公开演示只用合成/授权数据；重复调用不增加独立付费人数，日志不含单元格正文。

### P07-F21 模板库、批量和工作流连接器

优先级：P1。保存可版本化模板；批量仍按文件报价与交付；连接器需明确外部目标、权限和重试/重复导入语义。

验收：模板升级不改变旧任务；一个文件失败不吞其他结果；目标系统写入重试不重复创建订单，授权撤销后不继续写入。

### P07-F22 新领域与更大规格

优先级：P2。支持库存、账单、多工作表、更大文件/编码前，独立定义字段语义、行去向、计价和性能限额，不继承订单金额等假设。

验收：每个新领域有标准答案集、独立版本和报价，跨领域不能误套规则；新规格压力测试通过后才能开放收费。

## 选定稿与实施规则的明确差异

| ID | 图稿观察 | 定型实施规则 |

这些是对B的系统化细化，不引入其他方案的主色/版式。仅文字规则和变量定型，其他15页没有伪造单独图稿。

## 版本与修改

设计版本与业务版本分开：1.0.0对应P07 v3.0。后续校正说明/排版可用PATCH，新增兼容组件/页面规则用MINOR，改变核心视觉/交互合同用MAJOR。每次保留旧目录，新增版本写明原因、影响页/组件、业务变化、参照和核验结果，然后更新active；不可用同名覆盖来丢失历史。

实现中的尺寸/安全区/字体适配依据当前规则执行并记差异，不要求重新选型。只有后续用户要求改变方向才重新讨论风格；没有新指令不以原A建议覆盖B。

manifest记录本目录资产和对应定型文档，文件记录不含自身，manifest哈希由active指针保存。运行报告和备份ZIP存版本外，避免自哈希循环。只读约束由版本规则和核验检测执行，未宣称底层存储不可篡改或已异地备份。

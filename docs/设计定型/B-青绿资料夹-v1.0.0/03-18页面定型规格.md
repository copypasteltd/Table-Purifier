# B设计定型：18页面规格

P07-DS-B｜1.0.0｜2026-10-27。页面和组件映射见[pages.json](../../../assets/design/b-jade-folders/v1.0.0/specs/pages.json)，业务交互继承[18页原规格](../../小程序/02-移动端页面与交互规格.md)。下列18页均有规则定型；只有MP01/MP06/MP10有图像锚点，其他15页待逐页绘制/实现。

## 共用框架

根入口仅MP01整理、MP13任务、MP14规范、MP15我的；详情页原生返回，不重复四导航。每页先标题/关键信息，再核心内容，再唯一必要主动作。资料夹只强调一个归属对象，其余用索引标题+白行；没有需要推进的页面可没有强主CTA。正文与固定区域不互遮。


## MP01 整理首页

导航：根页，有底部四导航。

从上到下：宿主标题 → 短标题/无模板说明 → 资料夹资料区 → 规范模式 → 可选用途 → 检查资料 → 底部四导航。

主动作：检查资料。

优先放资料入口；已接收的合成3文件示例参照留存稿。实际首次进入为空状态，点资料夹进入来源添加。生成规范为正常入口，与我有规范同级。至少一项已收到可读来源才检查；不可读/超限就近提示。

必备状态：empty, draft, uploading, ready, permission-denied, offline。

组件：B-C01, B-C02, B-C03, B-C04, B-C06, B-C07, B-C08, B-C19, B-C20, B-C26, B-C31；关联需求：P07-F02, P07-F24, P07-F33, P07-F34。

## 与P1范围的关系

本次18个小程序页面直接关联38项P0需求。P07-F21持续追加与多人协作、F22更多格式与复杂规范、F28连接器/SDK/Machine Pay开放API、F42 Web进阶工作台为既有P1范围，不冒充已在这18页交付；后续另行细化时继承B视觉体系。42项业务范围未被减少。

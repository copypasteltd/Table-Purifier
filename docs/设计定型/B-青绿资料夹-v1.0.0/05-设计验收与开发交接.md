# B设计定型：设计验收与开发交接

P07-DS-B｜1.0.0｜2026-10-27。设计参照与文件核验已建立；实际小程序视觉/交互/无障碍及平台能力验收尚未执行。

## 开发读取顺序

1. 读[当前设计指针](../../../assets/design/active.json)，确认B、1.0.0和对应业务v3.0。
2. 读[定型总览](README.md)及当前页面规格，确认行粒度/主动作/状态语义。
3. 引用[tokens](../../../assets/design/b-jade-folders/v1.0.0/tokens.json)和[组件合同](../../../assets/design/b-jade-folders/v1.0.0/specs/components.json)，避免每页另写颜色/圆角。
4. 对照MP01/06/10三张裁片；其他15页按同一组件和规则实现，不套用A/D/E布局。
5. 补默认/空/加载/失败/拒权/离开恢复/版本冲突等状态，再进行双平台真机和视觉比对。
6. 在项目内保存脱敏截图和观察；若与冻结规范冲突，记录原因/影响，重要调整留新版本，不覆盖本次参照。

## 最小实现顺序

先做页面骨架/字体/颜色和资料夹→资料行/模式选择/按钮→规范摘要/字段目录/记录预览→问题/来源/决策→其余页面列表/表单→状态/键盘/安全区→四环境。后台解析/支付工作仍按业务实施计划，不把视觉组件完成当后端完成。

## 视觉差异分级

阻断：状态/颜色使用户误认付款、内容通过或已导出；看不到必要错误/操作；缺事实被画成真实值；隐私内容外泄。严重：改成其他风格、两模式不等价、来源隐藏、键盘遮按钮、触控过小。一般：非关键图标细微不齐、无语义的1—2像素边界差别。

禁止用整板像素逐点相同要求不同宿主，字体/系统栏的必要差异有记录即可；业务区域的层次、颜色、边距尺度、按钮和可读性要保持。无用户测量不声称效率提升/更高转化率。

## 留存完整性核验

运行本项目`scripts/verify_design_baseline.py`会核当前指针、文件SHA-256、32组件/18页关联、图片尺寸、声明色对与本地链接；它不是产品测试，不启动浏览器、Docker、WSL或任何平台工具。报告在项目评审目录，不能据此把B-V01—V14改PASS。

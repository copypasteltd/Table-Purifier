# B设计定型：组件与交互状态

P07-DS-B｜1.0.0｜2026-10-27。32组件的机器合同见[components.json](../../../assets/design/b-jade-folders/v1.0.0/specs/components.json)。所有组件当前是规格，不是已实现控件。

## 组件目录

| 编号/组件 | 作用 | 必备变体/状态 | 定型规则 |
| --- | --- | --- | --- |
| B-C01 宿主标题栏与页面骨架 | 页面名称/返回/宿主胶囊边界 | default, loading, offline | 系统区域由宿主保留；页面内容不侵入胶囊；详情页有返回，回到原列表位置。 |
| B-C02 资料夹分区 | 核心资料/规范/记录容器 | default, expanded, collapsed | 白底、青绿页签和顶线；每页最多一个重点资料夹，其余分区用普通行，不将每张卡拟物化。 |
| B-C03 索引分区标题 | 标记同层内容分组 | default, with-count | 左侧青绿短线配文字标题；索引线不参与点击，不表示数据通过。 |
| B-C04 主次与危险按钮 | 推进或确认动作 | default, pressed, loading, disabled, error | 主按钮纯青绿白字，次按钮白底青绿字，危险按钮深红；每一视图最多一个主动作，忙碌不重发。 |
| B-C05 图标动作 | 返回/更多/移除等操作 | default, pressed, disabled | 图标20/24，实际触控至少48设计单位；删除和清空有明确范围/后果，不只露一个难点叉号。 |
| B-C06 资料行与上传队列 | 显示来源角色/接收/解析状态 | selected, queued, uploading, received, unreadable, failed, expired | 文件名最多两行且可看全名；大小/来源状态文字明确，RECEIVED不写已解析；同名不覆盖。 |
| B-C07 规范模式选择 | 有规范与生成规范入口 | unselected, selected, disabled | 两项同级互斥，左/上为帮我生成规范；窄屏纵排，不挤小字；用选中圆点、边框和文字共同表态。 |
| B-C08 用途与文本输入 | 文字材料、可选用途、命名 | empty, focused, filled, invalid, disabled | 标签常驻，失焦/提交校验；清空可恢复未提交草稿；默认系统粘贴，不启动读剪贴板。 |
| B-C09 预检与报价摘要 | 范围/单位/排除/服务合同 | checking, ready, unreadable, limited, expired, unavailable | 费用单位明确，范围变化重新确认；局部预检不冒充全量，未开通通道不显示可成功收银。 |
| B-C10 阶段进度 | 服务端任务和待办提示 | queued, running, waiting-schema, failed, canceled, completed | 阶段名与已核实范围，不画虚构精确百分比；离开可恢复，关闭通知仍能查询。 |
| B-C11 推荐规范摘要 | 一行对象、字段数、规范状态 | partial-draft, full-draft, adopted, superseded | 重点资料夹显示行粒度；采用前标草案；部分草案不能当全范围正式规范。 |
| B-C12 字段目录行 | 字段名/规则/依据 | default, expanded, modified, missing, conflict | 名称、类型/单位、必填/可空和理由可读；仅出现一次的字段不删；图标不是唯一字段含义。 |
| B-C13 字段编辑与影响摘要 | 修改类型/规则/列序 | editing, preview, invalid, version-conflict | 增删/重排可操作，顺序有上移下移替代；关键变化先看影响，不自动放宽验收。 |
| B-C14 结果记录卡 | 一条候选的摘要与去向 | accepted, needs-review, excluded, unreadable | 显示3—5关键字段、明确状态/来源入口；同名不同人不借样式暗示已合并。 |
| B-C15 选列表格预览 | 少量列的代表预览 | sample, paged, empty, filtered | 手机默认卡片，预览少量列，必要局部横向滚动；表外页面不横溢；空值—不等于0。 |
| B-C16 问题状态条与标签 | 缺项/冲突/风险/未知提示 | missing, conflict, unknown, failed, expired, passed | 文字+图形+色彩；待补用琥珀色，失败深红，内容通过写明已通过，不以绿边框替代。 |
| B-C17 来源摘录卡 | 原文证据和定位 | available, loading, unreadable, expired, forbidden | 文字引文/文件页码、查看来源；链接按青绿token，不能补造来源或把模型重写当原文。 |
| B-C18 问题决策与金额输入 | 补缺、选依据、保留待补 | no-choice, fill-value, keep-unresolved, choose-evidence, invalid, submitting | 初始不替用户决定；补价须输入有效数和明确单位后能提交，保留待补明确提交后仍待补。 |
| B-C19 固定操作区 | 页面末端核心推进 | default, keyboard-visible, loading, disabled | 为正文预留高度和底部安全区；键盘弹出可看到输入/错误/按钮，不叠在宿主导航上。 |
| B-C20 四项底部导航 | 整理/任务/规范/我的 | unselected, selected, badge | 仅四根页面出现；相同线性图标、当前项青绿+文字；详情不用重复全局导航。 |
| B-C21 任务行 | 任务搜索/状态/恢复 | draft, pending-payment, running, waiting-schema, needs-review, ready, failed, expired | 同一任务修订不分成新订单；显示下一待办与期限，点击取服务端新版本。 |
| B-C22 私有规范卡 | 主动保存与复用模板 | saved, selected, new-version, deleted | 名称/字段数/版本；私有非公开；删除不改旧任务快照，去事实/证据/访问引用再保存。 |
| B-C23 交付文件卡 | 手机领取三常用文件 | ready, fetching, cached, open-requested, export-requested, confirmed, expired, failed | 结果Excel唯一强主色，空白规范/问题报告次按钮；获取/缓存/打开/实际导出措辞分开。 |
| B-C24 订单和退款状态块 | 原渠道付款/履约/售后 | pending, unknown, paid, fulfilling, refund-processing, refunded, failed | 金额/平台单位准确；客户端success非实付，退款处理中不写已到账；不跨平台外跳。 |
| B-C25 确认对话框与底部面板 | 明确有后果动作/有限选项 | open, submitting, error | 有取消/返回、可见标题和动作对象；长编辑用整页，关闭不等于保存，后果不能只写“确定”。 |
| B-C26 空/加载/失败反馈 | 帮助用户继续任务 | empty, loading, offline, failed, permission-denied, expired | 说明发生什么和下一步；慢任务可离开；失败就近保留重试，不能只闪toast。 |
| B-C27 隐私/权限与数据管理 | 按需同意及范围删除 | required, optional, denied, granted, revoked | 处理前必要告知，权限按需；不强制头像手机号；删除/模板/结果/账务分开说明。 |
| B-C28 短反馈消息 | 低风险动作确认 | success, info, warning | 仅用于已保存等可恢复动作；支付/采用/删除等结果在页面持久显示，不以短消息充当唯一证据。 |
| B-C29 搜索筛选与分页 | 定位记录和待办 | default, active, no-results, loading-more, end | 游标默认20，区分总候选与筛选结果；返回恢复筛选/位置，不一次渲染1000条及原图。 |
| B-C30 来源原文/页图预览 | 查看原资料证据 | text, image, zoom, loading, expired, forbidden | 按需加载、有页/段定位和返回；图可放大；真机能力未证不依赖宿主XLSX/PDF查看器。 |
| B-C31 平台能力说明 | 输入/交易/导出可用性 | available, restricted, not-approved, version-limited | 说明具体限制及获准替代方式；未证办公文件入口关闭，不用蓝绿成功标识掩盖受限。 |
| B-C32 版本冲突与修订摘要 | 采用/编辑/复验前核版本 | diff, stale, conflict, resolved | 保留本地草稿，展示新旧版本/影响再操作；旧请求不覆盖新结果，不重复扣轮次。 |

## 重点组件尺寸与组合

资料夹（B-C02）：外层12圆角、白面、16内边距；页签和顶线按视觉规范，仅一个重点容器。资料行（C06）起始最小64高，图标20/24，文件名16、辅助14，操作触控48，长文自动增高。移除键与整行打开分别命中，不嵌套误触。

模式（C07）：两项平等的真实互斥选择，常见宽度可并排，窄屏/大字号纵排。当前项边框、圆点和文案共同标记；生成规范不成为“升级/高级”入口。字段目录（C12）用名称+类型/规则+理由三层，来源长说明展开查看，不每行放一段长聊天。

按钮（C04）48高、优先52，主动作纯青绿白字；次动作白底绿边/字，普通链接绿字，危险动作深红及后果文案。加载保持宽高，展示正在检查/采用/提交，不能再次发送同动作。禁用原因在相关内容旁可见，不能只淡一个按钮让用户猜。

问题（C18）由记录值、问题、来源和用户决定组成，不直接给“全部自动修复”。补值选择展开带标签输入，金额未知不能默认为0。未填有效数值/明确单位不执行补值；选择保留待补并提交是有效决定，但不自动计内容通过。留存图的选中和主色按钮只是构图示例，初始状态以此规则为准。

交付（C23）三个常用文件中结果Excel为强主动作，空规范/问题报告为次动作；“更多文件”显示其余六项。每项版本和到期明确，点击后真实状态更新，不能把下载/缓存/打开/导出合并成一个绿色对号。

## 状态与用户文字

| 内部含义 | 用户文字示例 | 视觉与动作 |
| --- | --- | --- |
| 文件收到，未解析 | 已接收，等待读取 | 中性/信息色，不能写已完成整理 |
| 局部规范建议 | 初步建议，已分析部分资料 | 范围可见，不能正式采用成全量 |
| 全范围规范待采用 | 推荐规范，待你采用 | 行粒度/依据可看，主动作采用规范 |
| 引擎执行成功 | 整理完成 | 内容状态另列，不自动绿色“全部通过” |
| 结果缺事实 | 待补充：单价 | 琥珀标签与来源/决定入口 |
| 多来源不一致 | 有冲突：参加形式 | 候选来源并列，不默认最近上传为真 |
| 正式内容规则通过 | 规范核对通过 | 文字+可解释校验摘要，仍不宣称语义零漏抽 |
| 付款未确定 | 正在核对支付状态 | 查原单，不能再次支付 |
| 退款已申请 | 退款处理中 | 原通道确认才写已到账 |
| 文件只在宿主缓存 | 已保存到小程序缓存 | 明确局限，不写已保存至手机下载 |
| 来源到期 | 原件已到期 | 按实际保留摘要显示，不重新生成原文 |
| 当前端未开放 | 当前版本暂不支持此入口 | 说明获准可用方式，不绕收银或虚报能力 |

## 表单、浮层与反馈

字段有常驻标签、单位和必要规则，失焦和提交均校验但不在每次打字强移焦点。手机号/ID使用合适键盘只是输入便利，数据仍为字符串；金额以十进制规则校验，不能先转浮点损精度。问题不能只在toast中闪过。

危险删除/清空/规范关键变化用明确范围的确认；对话框有取消/返回，关闭不等于保存。长规范编辑、原文阅读使用整页，避免层层面板。Web/支持键盘环境的浮层管理焦点及Esc，原生按宿主能力适配，不假定统一DOM。

空状态先告诉用户可做什么，例如“添加资料，没有模板也能开始”；搜索无结果不等于任务为空。加载显示真实阶段，失败保持已完成内容和重试入口。通知拒绝、临时源失效、来源过期、版本冲突分别设计，不能全部归成“网络异常”。

## 图标与资源

自有文档/文件夹符号风格统一，选中导航可用同套填充变体。若采用第三方图标库，实施时锁定许可与版本；本文件不虚称已采购素材或官方品牌许可。图像参照不是需要一并加载的产品资源包，生产只用必要图标和真实渲染控件。

# B设计定型：视觉规范与设计变量

P07-DS-B｜1.0.0｜2026-10-27。数值源为[tokens.json](../../../assets/design/b-jade-folders/v1.0.0/tokens.json)，本页解释使用规则。仅浅色主题定型，深色不是本版本交付范围。

## 视觉语言

资料夹页签用于说明“这一组材料/这一套规范/这一条记录”的归属，不能只是每张卡上重复的装饰。每页最多一个重点资料夹分区；其他区块用短青绿索引线、文字标题、轻分割和普通行。内容区白底，页面淡雾绿，避免暖黄纸纹、叶子插画、厚折角和夸张阴影。

页签宽64—80 LU、高12—16 LU，位于容器顶边，顶线约4 LU；不放必需可读文字。基础圆角8—12 LU；优先用简单圆角几何/受支持矢量实现，不为复刻斜角依赖未核实的复杂遮罩。页签不遮标题，白底正文顶部至少16 LU留白。小屏/大字可简化页签，保留索引和分组。

## 色彩和语义

| 角色 | 定型值 | 用法 |
| --- | --- | --- |
| 页面背景 | #EAF1EE | 雾绿，只承载页面，不作为低对比正文前景 |
| 阅读/控件面 | #FFFFFF | 文件、字段、来源和记录阅读区 |
| 次面 | #F6F9F7 | 表头、辅助区域，避免层层套灰 |
| 正文 | #203C32 | 深绿墨色，重要标题和事实值 |
| 次级文字 | #5E7167 | 来源、解释和辅助信息，仍须可读 |
| 主色/链接 | #17745E | 核心动作、当前导航、选中边框、普通文字链接 |
| 按下主色 | #105F4D | 主按钮按下反馈，不改变按钮大小 |
| 选中淡底 | #E8F3ED | 和圆点/文字一起表明选中，不意味着内容通过 |
| 分割线 | #D4E2DA | 纯结构装饰，不能充当控件唯一可见边界 |
| 控件边界 | #6F897C | 白面/页面上的必要输入/选择边界，配可见标签 |
| 资料夹页签/顶线 | #BED8C9 / #4A8B70 | 只作结构识别，不承载长文字 |
| 提醒 | #875A18 on #FFF3DB | 缺项、冲突、需补充，配具体问题文字 |
| 错误 | #B33E32 on #FDF0ED | 失败、危险动作；不要把每个缺项都渲成事故 |
| 信息 | #306071 on #EDF4F6 | 查询中、说明，不虚称完成 |
| 金色点缀 | #BD8A33 | 装饰或和深色字组合，不作白底小字 |

白字主按钮#17745E与白的静态对比约5.68:1；正文对白约11.97:1，次级文字对白约5.21:1、对页面约4.54:1。具体所有声明配对由[颜色对比记录](../../../assets/design/b-jade-folders/v1.0.0/specs/contrast-report.json)计算，结果只证明这些颜色对，不等于完整无障碍达标。禁用态不只降低透明度，文字说明为什么不可操作。

原选定图的“查看来源”是蓝色生成效果，实施统一青绿链接，并用下划线或箭头/明确动作名提供识别。文件类型小图可以保留PDF红、图片绿等来源符号，不把这些类型色扩成第二套品牌主色。

## 字体与字号

系统中文无衬线为唯一基础字族：按宿主系统使用PingFang SC/平台中文字体，设计参照页可回退Microsoft YaHei。标题与字段用600/500，正文400；数字可用等宽数字特性，能力不支持时系统字体回退。无需额外网络字体，不因英文品牌设计引入中文衬线体。

| 角色 | 字号/行高 LU | 字重 | 位置 |
| --- | --- | --- | --- |
| 页面核心短标题 | 24 / 34 | 600 | 整理首页，不在每个详情重复大标题 |
| 原生应用标题参考 | 17 / 24 | 600 | 以宿主真实标题栏为准 |
| 分区标题 | 18 / 26 | 600 | 资料/字段/来源标题 |
| 字段标签 | 16 / 24 | 500 | 列名、记录标签 |
| 正文/输入 | 16 / 24 | 400 | 事实、表单、说明主文 |
| 帮助文字 | 14 / 22 | 400 | 解释、文件状态与必要来源 |
| 辅助标记 | 12 / 18 | 400 | 次要时间，不承载唯一错误或重要金额 |
| 操作文字 | 16 / 24 | 500 | 主次按钮 |
| 重点数值 | 20 / 28 | 600 | 订单实付/必要统计，不能压过任务本身 |

长字段、文件名、用途允许换行；关键字段/问题/金额不截断成无法判断。文件名最多先显示两行，另有详情可看完整；所有值不随意压缩字号。不得为了表格塞九列把正文降为小字。

## 尺寸、间距与单位

LU是375宽参考稿坐标，不是对rpx/dp/pt的等同声明。页面左右16、分区间24、行距8、分区内16、行内12；间距尺度4/8/12/16/20/24/32/40。布局可弹性适应320/375/390/430宽，字体和触控下限不跟窄屏等比缩水。宿主单位转换详见[双平台适配](04-双平台适配与Web延展.md)。

主按钮高48、优先52，输入最小48；图标可20/24但触控至少48×48 LU参考范围，独立动作间距至少8。实际两OS按真实渲染/系统缩放测量，不凭32rpx等数字宣布符合触控要求。

列表不把所有行都固定为64高；64是来源/字段行的起始最小高度，文字多就增长。圆角标签4、控件8、行10、分区12、面板16。默认卡片无阴影，用白面/线条分组；只有浮层用轻阴影。边线1，键盘焦点2；原生平台按真实像素/密度适配。

## 图标、动画与主题

使用一套线性矢量图标，20/24尺寸、约1.75线宽、圆端；根导航选中可用同套填充变体。图标旁有文字时装饰图不重复朗读，独立动作要可访问名称。不能用emoji、彩色3D图和不同图标库随意拼接。

按下约100ms、一般状态反馈150ms、面板约220ms作为设计参考；不在每页转场额外加动画。减少动态时改为即时/极短；上传和处理靠真实阶段，不跑装饰性无限动画占内存。颜色/透明度反馈不改变布局边界。

默认浅色，不能自动将所有hex取反作深色主题。若宿主强制深色影响页面，需要逐端核实适配/保持浅色的允许方式并测可读性，未测不宣称已支持。主题新增应另行给全套语义色和状态对比。

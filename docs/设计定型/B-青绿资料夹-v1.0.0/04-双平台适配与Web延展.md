# B设计定型：双平台适配与Web延展

P07-DS-B｜1.0.0｜2026-10-27。对应P07-F33—F42；这里只定义设计和适配职责，不证明平台SDK、文件路径、交易或跨端权益已开通。

## 共用与原生边界

| 内容 | 双端共用 | 各端原生/独立验证 |
| --- | --- | --- |
| 视觉 | B语义配色、字体角色、资料夹/索引语言、记录/问题/来源层级 | 原生系统字体度量、状态栏/胶囊尺寸和设备密度 |
| 导航 | 四根入口及18页关系，详情返回保留上下文 | 宿主返回、标题栏、胶囊、系统手势和深链 |
| 输入 | 可见标签、材料/规范角色、字段规则、上传状态 | 登录、隐私、拍照/选图、普通文档选择路径、键盘 |
| 交易 | 范围/单位/订单/未知/退款文案及权益判断 | 各平台已获准商品/收银/查单/退款、iOS资格 |
| 结果 | 卡片、选列预览、问题和来源、自有九文件 | 下载/缓存/打开/实际导出，回执不能自造 |
| 生命周期 | 服务端为准、可恢复、通知非强制 | 前后台事件、临时路径、网络和可选订阅 |

不要仿画支付成功、系统授权框或胶囊让用户误认原生事实。业务主色保持青绿；平台原生收银/授权保留宿主外观。普通文档/交易未支持的单元使用B说明组件呈现真实限制，不给可成功的假按钮。

## 单位、屏幕与字体

375 LU为参考画布，布局左右16 LU。工程层提供语义token转换，不能将LU简单声明为rpx/dp/pt：相对长度仅在目标宿主支持且实测后转换；字体、输入、触控下限必须防止随320窄屏等比缩小。Web参考页的1LU=1CSS px只是该参考实现，不是小程序通用单位合同。

字体继承宿主/OS系统字体，测长中文/全角、数字和回退。320/375/390/430宽分别检查；大字号让字段/列表高度增长，模式选择从两列变一列，按钮可以纵排，不能缩字或压触控。横屏不强塞双栏；需要阅读区宽度和安全区保持，来源图可放大。

外层只保留一个主要纵向滚动区，底部操作区预留自身高度+安全区+16。固定按钮不得与根tabBar重复占位；MP01/13/14/15根页有tab，其他详情按返回与必要操作栏。键盘出现时输入、错误与提交可见；长规范编辑必要时整页，不用小面板硬塞。

## 资源与文件

参照PNG用于设计比对，不作为实际页面背景/整图点击区；文字/按钮/选中/错误以真实控件实现。产品图标为矢量/宿主可用格式，平台不支持的格式先验证再转换，不引入多套风格。文件列表缩略图按需加载，非必要不预载原图/九文件。

视觉证据不包含客户真实资料；样例保持合成。来源页和缩略图是私有内容，不作公共分享卡。网络/存储限制仍见[文件进出规格](../../小程序/03-双平台能力与文件进出.md)。

## 可靠性和反馈

按下先给稳定反馈，提交中禁止重复；超时显示待核对/可恢复，不重新创建订单。前台重入拉服务端状态，不用本地倒计时断言已退款或已过期。拒绝通知不影响任务列表，拒相册可使用已开放其他入口。

保存到缓存、发起打开、导出操作与用户实际取用分开显示。B的整洁视觉不能把这些差异缩为一个绿色“完成”。权限/网络/报价过期/来源到期也要分别表达。

## Web进阶P1

Web保留青绿、白面、字段目录/来源索引；1024以上可分资料/结果/证据三栏，宽度由实际容器与字体测试决定，不从手机板拉伸复制。768—1023可主区加抽屉，窄屏回单列；这里只是布局建议，不新增首版网页依赖或承诺所有断点已实现。

大屏批改、并排预览、键盘焦点、选区和版本冲突沿用同一业务合同；可访问名称与焦点态齐全。Web编辑先预览影响/复验，不直改输出后声称通过。协作/多表/更大规模另按P1需求扩展。

文件辅助接力/领取页如平台允许，仅按指定任务安全传文件；其B视觉可简化成白面标题/文件列表/明确动作，不作为进阶编辑或受限平台的收款后门。跨端账号绑定不自动共享付费权益。

## 四环境设计验收

支付宝Android、支付宝iOS、抖音Android、抖音iOS各记录设备/宿主/基础库/构建、字体/安全区/键盘、大字、入口、限制和截图。当前均未执行；本定型不会把既有能力清单的关闭开关改成可用。平台变化只针对适配区域处理，并登记差异，保留B核心语言。

## 56项自有接口

S1 创建会话并完整预加载Skill → S2 用户提交信息 → S3 Agent分析 → S4 用户确认或调整 → S5 预估计费 → S6 实付后批量产出 → S7 独立保存结果、释放Agent并销毁任务运行环境。

## 通用约束

服务端owner、写幂等键、expected_version、UTC、精确金额/decimal，统一request_id与错误。鉴权session不等于Agent session；外部不能指定任意thread/服务器路径/命令。API18—20是Task级付费前规范接口，旧Run路径退出当前草案。未知操作查原operation；UNKNOWN支付不新收款。结果读取不依赖Agent存活，下载签名过期可续。

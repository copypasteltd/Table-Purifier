## 24项原业务异常

| 场景 | 给定/操作 | 预期 |
| --- | --- | --- |
| P07-E01 没有模板/用途为空 | 会话已完整预载并READY，用户仅添加可读材料；不上传模板且用途留空，点击检查资料并确认允许范围 | 付费前全范围分析并推荐规范；用户确认后才报价，不要求先付发现费 |
| P07-E02 模板包含样例 | 表头下带一行公司示例；选择带样例的模板与独立源资料，确认目标后执行并查看候选 | 示例只解释规则，不成为源事实或候选 |
| P07-E03 多主题不同粒度 | 联系人与订单混合；提交联系人和订单材料，响应主表澄清后查看未纳入信息 | 只澄清本次主表，其他重要内容明确未纳入 |
| P07-E04 稀有字段 | 三份报价只有一份写保修；运行三份报价的全范围发现，展开字段建议与代表预览 | 保留可空保修或明示未纳入，不向别行复制12个月 |
| P07-E05 无单价 | 原文为单价待议；采用必填单价规范并整理单价待议报价，查看问题详情 | value=null/MISSING，不能补0，必填时不通过 |
| P07-E06 冲突多来源 | 同一对象两份材料交期不同；打开同一对象的交期冲突问题并展开两个来源，不作选择 | 保留两个候选及来源，初始不选最新值 |
| P07-E07 非法补值 | 选补价但空输入/格式不合法；选择补充单价，分别保持空值/输入非法文本并尝试提交 | 内联错误、提交禁用，不生成决定或扣修订 |
| P07-E08 保留待补 | 用户明确KEEP_UNRESOLVED；选择保留待补并提交，等待原操作完成后重查质量状态 | 保存决定与说明但质量仍待核，不自动通过 |
| P07-E09 旧草案采用 | 另一端已更新proposal；在提案已更新后提交携旧proposal_version的采用请求 | 409保留未提交稿，刷新比较；不改旧绑定 |
| P07-E10 重复采用 | 网络超时后重放同键；在采用已提交但响应丢失后，用同幂等键和载荷重放 | 返回同一Binding/operation；不启动Run，方案确认后才能报价 |
| P07-E11 分页期间修订 | 旧cursor绑定结果4但现为5；取第一页后提交修订生成新版，再用原cursor取第二页 | 明确快照或409刷新，不把新旧分页拼接 |
| P07-E12 重复修订提交 | 同batch幂等重放两次；已完成任务两次重放同修订意图，核新会话预载和之后的确认估费/实付权益 | 只建立一个新会话修订意图；完成七步前置条件后最多一child Run，失败释放预留，不复活旧环境 |
| P07-E13 平台漏识别 | 原资料保修被漏抽；标记原资料已存在但未抽取的保修字段，发起平台纠错复验 | 新会话重新提供必要原件，确认估费后核原实付纠错权益，不扣用户轮次或要求新付；不恢复已销毁源上下文 |
| P07-E14 执行后发现超限 | 第51单元/第1001候选；处理到第51单元或第1001候选时检查预算与范围报告 | 停止新增计算、说明已读/未读，原合同处理；不截断冒完整 |
| P07-E15 worker旧租约 | 重试新attempt后旧worker完成；令旧worker租约失效后新attempt执行，再恢复旧worker提交 | 旧输出不发布/不覆盖，审计并清临时内容 |
| P07-E16 支付未知 | 客户端success但服务端未核实；仅触发客户端支付success而不提供服务端确定付款事实 | 显示核对中，查原单，不放行或再次付 |
| P07-E17 支付晚到 | 用户离开/订单显示过期后正式付款事件到；订单内部到期后注入正式可验证的晚到支付事件并对账 | 查原通道事实；不得消失已付记录；按原范围履约或原路退 |
| P07-E18 取消与完成竞态 | 取消和原子发布同时发生；在结果原子发布边界同时提交取消，查询最终执行/退款/权益 | 条件更新只有一分支生效，退款/权益据最终事实一致 |
| P07-E19 退款请求未知 | 通道提交超时/重复回调；让退款提交响应丢失，重查同单并重放重复退款结果事件 | 查同退款单，累计不超原实付，不把申请写到账 |
| P07-E20 导出只有缓存 | saveFile或下载成功无真实系统保存证据；完成下载或应用内saveFile但不提供系统导出回执，查看文案 | 只显示缓存/获取；记录用户确认和平台回执不同，不重收费 |
| P07-E21 环境已销毁后看来源 | 九文件持久保存，原始运行环境已销毁；清理原件而保持结果摘录有效，打开来源页和原图操作 | 原件无法全文预览明确说明；结果内必要摘录/定位仍有效，不自动过期、不伪造原件访问 |
| P07-E22 清运行环境与执行竞态 | 删除请求时worker仍运行；worker处理时请求关闭任务运行环境，再恢复旧worker尝试发布 | 先fence并停止进程树，旧worker不得发布；已发布结果不删除，清理失败不得标成功，必要订单/清理凭据独立保留 |
| P07-E23 私有规范复用 | 另存后源被删除；主动另存规范后删原件，在本人新任务选用同模板版本 | 模板可在本人新任务复用，无真实样例/证据/访问引用 |
| P07-E24 未获准收费 | 当前app/SKU/OS未开通；关闭当前app/SKU/OS收费资格，从客户端直接请求收银接口 | 服务端拒新收银，显示范围；不引导Web/其他端付款 |

# Agent整理与独立验收规格

P07｜业务v3.2｜开发P07-DEV 3.0.0｜2026-10-27｜设计B青绿资料夹1.0.0。设计资料，软件及真实Agent/资金/设备测试未执行。

S1 创建会话并完整预加载Skill → S2 用户提交信息 → S3 Agent分析 → S4 用户确认或调整 → S5 预估计费 → S6 实付后批量产出 → S7 独立保存结果、释放Agent并销毁任务运行环境。

所有新资料处理任务均执行统一七步；PROVIDED和DISCOVER只影响规范来源，不能改变步骤顺序。查看已保存结果走独立结果服务，不启动新Agent或重复收费。用户调整返回分析与确认，旧确认和未付报价失效。结果文件独立保留；整个任务container销毁。本地container指受限Windows原生任务环境，禁止Docker/WSL/VM/MXC。

首版支付宝与抖音原生小程序均为P0，Web/API为P1；未来入口亦须遵守同一合同。保留B视觉/18页/32组件，首页增加会话初始化/完整技能加载/失败状态。模型/SDK/权限/认证、价格和平台能力必须实证，不能以本资料为上线或测试通过。

## Agent阶段权限

BOOTSTRAP无客户内容，完整技能先装；ANALYZE/ADJUST全范围理解和至多5条预览；BATCH/REPAIR需已确认计划/绑定及实付回执，才能生成九文件。读取方法、代码与工具顺序由Agent自主决定，独立验证不能被Agent改写。

## 计量定义

文件数只数SOURCE的已确认文件，文本另合计码点；单/总源字节以接收原件实测为准，规范文件独立5MB，不因转换后变小绕上限。同摘要且同角色重试复用同一资源；用户明确作为另一次业务资料时记录duplicate_relation，不能自动删事件。

PDF每页1单元（空页也要有覆盖去向）；一页中的OCR区域不重复计页。独立图片每张1单元，多图顺序可确认。DOCX先确定性解析为有序段落和表格行块，正文按最多4,000码点分块，单表行不跨块；超大单行单独块并受资源限制。块算法版本、顺序与总数在付费前分析与确认方案时锁定，不用不稳定页码计费。

用户直接粘贴/提交文本按合计50,000码点控制；TXT/Markdown文件按原字节及解析资源限制，其他文件抽取文字不以粘贴限额静默截断；CSV/XLSX按总量/候选/列与解析展开限制，不假定每工作表等于1 OCR页。格式展开限制是工程防护，必须在预检说明且不能用只处理前几行冒充全量。扫描结果/候选数在执行才确定的超限，停止并展示已读/未读范围，按原合同纠正/退款或明确新范围。

## 格式行为

| 输入 | P0读取 | 不默认承诺 | 定位 |
| --- | --- | --- | --- |
| 文本/TXT/Markdown | 原文段落、显式列表/表格 | 执行代码、抓外链、理解所有乱码编码 | 字符区间/段落 |
| CSV | 明确编码/分隔、完整原值 | 自动猜无证据编码、执行公式 | 行/列及raw |
| XLSX | 单元格存储值、基础格式/日期系统、明确区域 | 重算公式、执行宏、复杂图表/嵌入物 | sheet/cell/range |
| DOCX | 段落/表格及确定性块 | 完整重现Word分页、复杂批注/浮动对象 | paragraph/table/row |
| PDF | 文字层及必要OCR页图 | 所有版式完美还原、密码破解 | page/bbox/span |
| JPG/PNG | 图片OCR与可定位片段 | 低清手写必准确、隐含常识 | image/bbox |

未支持结构列入可读性报告；XLSX公式若使用缓存值，需标缓存且校其可信/时效，不能声称已重算。未知值保留来源和问题。

## 规范合同

规范最少包括schema_id/version/origin、用途、row_kind、fields（稳定field_id、唯一label、order、type、required、nullable、unit/scale、description）、已批准identity_keys/跨字段规则、locale/timezone/舍入和安全导出策略。类型为TEXT/DECIMAL/INTEGER/BOOLEAN/DATE/DATETIME/ENUM；复杂数组/多表后续独立定义。

required表示该字段对每个适用记录必须有值；nullable表示空值允许性，required=true与nullable=true必须有明确适用条件，不接受矛盾规则静默运行。空字符串不是缺失默认；0/false是有效值，不能用truthy判断必填。枚举先默认开放，只有规范明确封闭且有依据才拒绝集合外值。标识用TEXT，decimal用字符串并配单位/币种。

规范规则DSL与Agent自己编写的受限清洗脚本分开：跨字段规则只支持受限表达式树，如compare/and/or/required_if及批准decimal运算，禁任意eval/SQL/Python/外链函数。规则编译有深度/长度/运行时间上限；实际正则限制在实现试验后锁定，不能执行不受限回溯。

## 无模板发现与适合性检查

分析所有已确认单元的主题和对象候选，先决定行粒度，再聚合字段。字段出现频次是证据，不是重要性：报价保修仅1/3来源存在仍可能是关键比较项，保留可空；相关记录分母应为可适用的商品报价数，不是总文件数。多主题分别列出候选主表/重要未纳入项。

每个FieldSuggestion保留label/type/unit/nullable/规则建议、reason、evidence_ids、observed_count/relevant_count、是否来自样本及歧义。无法从资料证明的约束标建议，用户批准后才冻结。FULL只说明约定范围分析结束，不声称原不可读内容已理解。

预览最多展示代表记录摘要，清楚标样本及总候选是否已知；不能把3行称全量、不能把规范示例当正式事实。用户采用前可自然语言修改，系统给变更差异及影响：改粒度影响哪些记录、删列移出哪些信息、必填/单位/归并变更导致哪些待核。

## 事实提取、归并与来源

每字段同时保存raw_text、typed_value、status、evidence_ids、transform_chain、rule_version；派生值记录表达式和依赖字段，人工值有actor/说明。纯规范格式化不改变事实含义，单位换算和默认必须有规则，缺失不能用常识补造。

证据必须指向本任务可访问来源单元，坐标在边界内，摘录可与解析原文对应；金额、标识等关键字段还核原文字符。只证明“存在一段文本”仍不足证明结论对应，需核对象关系和业务语义。无法确定归属则保留候选/问题。

合并只用批准稳定键及对象关系；姓名相似、上传较新不默认更真。相同对象的矛盾值保留多候选，用户选依据或补充。拆一份名单成多记录、多份材料补一行均保存关系；重复报价事件不能因为内容相同就删掉。

## 问题与验收结果

Issue至少code/severity/record/field、来源候选、影响、allowed_decisions。缺字段、冲突、OCR歧义、单位/日期歧义、无证据、规则失败、粒度/规范遗漏分别编码。缺事实与平台漏识别分开用于修复/收费政策；该分类可被人工纠正并留审计。

行去向ACCEPTED/NEEDS_REVIEW/EXCLUDED恰一类。可选字段MISSING且规范允许时行可ACCEPTED，但关键歧义、未批准派生或必填缺失仍待核。EXCLUDED需原因、范围及适用用户确认，不把难行移出以抬高通过率。

quality_status：NOT_EVALUATED未有有效绑定/结果；PASSED为约定范围与规则/证据/重要信息校验均无未解决阻断；NEEDS_REVIEW有可解释待补/冲突；BLOCKED为缺有效规范、严重范围/事实/结构问题。PASSED是当前合同的验证结论，不宣传现实世界事实绝对真或专业认证。

validation.json分列schema_fitness、information_coverage、rule_validation、evidence_validation、source_coverage、candidate_dispositions、limitations。独立人工标准答案统计质量见[非功能/指标](04-非功能安全与运营需求.md)，不得用自造schema100%符合率替代。

## 九文件发布与互通

result.xlsx主表只保留目标字段，_states/_issues/_sources/_excluded附表说明状态和定位；同label安全改名规则与原字段映射可查。accepted.csv只导出通过行；result.json包含所有候选及移出原因。standard.xlsx/json无本次真实数据/证据访问引用。

统一字符编码/日期与decimal策略；CSV建议UTF-8 BOM并声明分隔与危险公式保护。危险前缀=、+、-、@及前置控制字符在文本字段按安全策略转义，不错误把真实数值负数当任意文本。转义保留raw和说明，重新导入有明确解码策略。

manifest固定其他8文件哈希/字节/版本/到期，自身哈希接口另返；zip不是手机必须一次下载。产物先临时、回读校schema/候选数/列序/哈希、再原子发布，失败不暴露半套READY。已绑定规范但0候选可有诊断包，不能生成假业务行或标严格服务已履约。

# 用户故事与业务规则

P07｜业务v3.2｜开发P07-DEV 3.0.0｜2026-10-27｜设计B青绿资料夹1.0.0。设计资料，软件及真实Agent/资金/设备测试未执行。

S1 创建会话并完整预加载Skill → S2 用户提交信息 → S3 Agent分析 → S4 用户确认或调整 → S5 预估计费 → S6 实付后批量产出 → S7 独立保存结果、释放Agent并销毁任务运行环境。

所有新资料处理任务均执行统一七步；PROVIDED和DISCOVER只影响规范来源，不能改变步骤顺序。查看已保存结果走独立结果服务，不启动新Agent或重复收费。用户调整返回分析与确认，旧确认和未付报价失效。结果文件独立保留；整个任务container销毁。本地container指受限Windows原生任务环境，禁止Docker/WSL/VM/MXC。

首版支付宝与抖音原生小程序均为P0，Web/API为P1；未来入口亦须遵守同一合同。保留B视觉/18页/32组件，首页增加会话初始化/完整技能加载/失败状态。模型/SDK/权限/认证、价格和平台能力必须实证，不能以本资料为上线或测试通过。

## 24条业务不变量

| ID | 规则 |
| --- | --- |
| BR01 | 所有新处理任务先建独立Agent session并完整预载Skill，READY后才收信息；无模板进入DISCOVER |
| BR02 | SOURCE与TARGET_TEMPLATE由角色决定，不按文件名猜；样例不进事实 |
| BR03 | 一任务一个主要结果表；行粒度明确，异粒度不强合 |
| BR04 | 用户确认准确源/目标/规范/规则/策略/计划版本后冻结合同，之后才能估费；变更令旧确认与未付报价失效 |
| BR05 | 付费前Agent完整分析拟处理范围、提出方案与最多5条代表预览；不生成正式批量包，初始化/分析限额由平台承担 |
| BR06 | PARTIAL草案不能正式采用；FULL说明全确认范围的处理与不可读项 |
| BR07 | PROVIDED与DISCOVER均在报价/付款前采用准确规范并确认执行方案；付款不代替确认 |
| BR08 | 稀有重要字段保留或明示未纳入，样本不推出必填/唯一/封闭枚举 |
| BR09 | 缺失为null+状态；缺价不补0，待议是业务原文而非数字 |
| BR10 | 默认/派生/人工值显式标记，不冒充提取事实；证据不可转移 |
| BR11 | 归并用批准稳定键；同名/同电话/重复文件不自动证明同一事件 |
| BR12 | 每源单元有去向，每候选唯一去向；覆盖不是语义召回100% |
| BR13 | 独立校验规则、事实/证据、规范合理性、重要信息覆盖 |
| BR14 | 结果版本不可变；任务运行环境产出后销毁；修订新session完整预载、确认、估费、核实实付权益后新child Run |
| BR15 | 初始无问题决定；补值有效才提交；保留待补不等于通过 |
| BR16 | 相同幂等请求返回原动作，旧版本写409；网络未知先查 |
| BR17 | Run、schema、quality、artifact、payment、refund、fulfillment、export独立 |
| BR18 | 客户端success/UNKNOWN不放行生产；只有服务端确认原渠道实付且plan hash匹配才启动批量，正常消费者无FREE绕过 |
| BR19 | 超限不截断、不隐性加费；平台漏读/错误为纠错，不扣用户轮次 |
| BR20 | 0候选不收费/已付全退；严格/尽力政策事前选择不事后降级 |
| BR21 | 九文件独立可靠保存/回读并原子发布后，释放Agent并销毁运行环境；结果不随环境清理，设备缓存不代表导出 |
| BR22 | 私有规范主动另存去事实/证据/访问引用，独立授权与到期 |
| BR23 | 未获准平台/SKU/OS能力关闭；不借Web/其他端引导绕收费 |
| BR24 | 销毁整个流程container包括输入/上下文/代码/中间物/临时/正文日志及受控副本；保留独立结果、私有规范与最小订单/清理凭据 |

# 数据字典与状态迁移

P07｜业务v3.2｜开发P07-DEV 3.0.0｜2026-10-27｜设计B青绿资料夹1.0.0。设计资料，软件及真实Agent/资金/设备测试未执行。

## 关键实体

AgentSession先于Task：session ID/owner/status/Skill manifest hash/preload receipt/工作区/cleanup/result ID。Task在READY后创建，持有来源/目标/规范草案。ExecutionPlan记录版本、source/binding/Skill hash、策略和用户确认；确认后Contract/Quote/Order绑定它。Batch Run仅在实付后创建，Result与结果投影独立于会话环境。

类型：UUID服务端ID；UTC时间；金额整数+原单位；事实decimal字符串；标识文本；原文件hash与canonical JSON hash分开。字段保raw/value/status/来源；每候选唯一去向。

## 状态轴

- execution：QUEUED, RUNNING, SUCCEEDED, FAILED, CANCELED。
- schema：NOT_REQUIRED_YET, PARTIAL_DRAFT, FULL_DRAFT, ADOPTED, SUPERSEDED。
- quality：NOT_EVALUATED, PASSED, NEEDS_REVIEW, BLOCKED。
- artifact：NOT_READY, BUILDING, READY, FAILED, EXPIRED, REVOKED。
- payment：NOT_CREATED, PENDING, CONFIRMED, FAILED, CLOSED, UNKNOWN。
- refund：NONE, REQUESTED, PROCESSING, SUCCEEDED, FAILED, UNKNOWN。
- fulfillment：NOT_STARTED, IN_PROGRESS, DELIVERABLE, DELIVERED, FAILED, CANCELED。
- operation：PENDING, SUCCEEDED, FAILED。
- export_observation：ARTIFACT_READY, FETCHED, CACHED, OPEN_REQUESTED, OPENED, EXPORT_REQUESTED, USER_CONFIRMED, PLATFORM_CONFIRMED, FAILED, UNKNOWN。
- session：INITIALIZING, READY_FOR_INPUT, INPUT_RECEIVED, ANALYZING, WAITING_CONFIRMATION, QUOTABLE, AWAITING_PAYMENT, BATCH_QUEUED, BATCH_RUNNING, PERSISTING_RESULTS, RELEASING_RUNTIME, CLOSED, INITIALIZATION_FAILED, FAILED, CANCELED。
- cleanup：NOT_REQUESTED, PENDING, STOPPING, DELETING, SUCCEEDED, FAILED。

## 会话迁移

| 从 | 到 | 守卫 |
| --- | --- | --- |
| INITIALIZING | READY_FOR_INPUT | 完整Skill包内容/清单/hash实际装入上下文且工具/权限自检通过 |
| INITIALIZING | INITIALIZATION_FAILED | 任一资源缺失/超上下文/认证或权限失败；不接受客户资料 |
| READY_FOR_INPUT | INPUT_RECEIVED | 用户主动提交获授权文字/文件，创建关联任务 |
| INPUT_RECEIVED | ANALYZING | 在独立分析预算内开始读取资料 |
| ANALYZING | WAITING_CONFIRMATION | 全部拟处理范围账本与规范/计划/代表预览已齐 |
| WAITING_CONFIRMATION | ANALYZING | 用户调整内容，递增计划/输入版本，旧确认与未付报价失效 |
| WAITING_CONFIRMATION | QUOTABLE | 规范已采用，用户明确确认准确执行方案 |
| QUOTABLE | AWAITING_PAYMENT | 可信计量与获准价格表生成绑定版本的报价/原订单 |
| AWAITING_PAYMENT | ANALYZING | 用户调整且原订单未付已确定关闭；UNKNOWN先查原单 |
| AWAITING_PAYMENT | BATCH_QUEUED | 服务端核实原实付和计划hash；仅创建一次生产意图 |
| BATCH_QUEUED | BATCH_RUNNING | 领取有效租约并再次核实实付/计划/权限 |
| BATCH_RUNNING | PERSISTING_RESULTS | Agent九文件候选与独立验证完成 |
| PERSISTING_RESULTS | RELEASING_RUNTIME | 九文件复制独立结果区、hash/readback/持久提交及outbox原子成功 |
| RELEASING_RUNTIME | CLOSED | Agent进程树结束、受控正文/工作区/会话/副本清理证据齐，结果继续保留 |

## 并发与终态

同会话单turn、同合同单活动计算租约；所有写按owner/expected version/fence/epoch。Run终态不重开。付费前没有等待规范的生产Run，等待在session轴。结果发布与清理outbox原子，结果READY/cleanup FAILED可同时成立。用户/支付等待不计活跃计算，环境闲置期限单独配置。销毁后仅最小元数据/结果存续，不保留可恢复正文。

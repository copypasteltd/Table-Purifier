# 独立验收、持久结果与私有规范

P07｜业务v3.2｜开发P07-DEV 3.0.0｜2026-10-27｜设计B青绿资料夹1.0.0。设计资料，软件及真实Agent/资金/设备测试未执行。

S1 创建会话并完整预加载Skill → S2 用户提交信息 → S3 Agent分析 → S4 用户确认或调整 → S5 预估计费 → S6 实付后批量产出 → S7 独立保存结果、释放Agent并销毁任务运行环境。


Agent生成九文件候选：standard.xlsx/json、result.xlsx、accepted.csv、result.json、issues.xlsx、provenance.jsonl、validation.json、manifest.json。规范空白无本次真实源值；result含全部候选和状态/移出依据，accepted仅通过行。准确数值/编码/日期/危险公式保护需要回读；manifest核其他8文件，自身hash由外层返回。

独立验证器核冻结规范、来源/摘录/定位、规则、完整范围/重要信息与候选唯一去向，Agent自评不是通过。反馈可让Agent在已付预算内修候选，不能改标准/验证器或删难行。0候选交诊断不造行。

发布器把九文件复制到独立结果区，按真实存储语义核持久提交、hash/readback及fence/权限，短事务提交Result指针和清理outbox后才销毁整个环境。结果留存及下载不依赖workspace。来源只留结果必要摘录/定位，不暗存全原件。私有规范用户主动保存、去事实/证据/访问引用，独立于任务环境。

## 实施细则

## 独立验证器

Validator 输入 immutable binding、source_set/coverage、candidate records、field/evidence/lineage、decisions、parser/rule 版本。它不能写新业务事实、改规范/删困难行来让结果通过。模型自评、合法 JSON、字段齐全都不能单独得出 PASSED。

| 检查 | 判定对象 | 失败行为 |
| --- | --- | --- |
| schema_fitness | row_kind、字段/单位/粒度、关键未纳入信息 | 严重不适合 BLOCKED；可澄清项 NEEDS_REVIEW |
| information_coverage | 人工/规则识别的重要已有信息去向 | 列遗漏/移出，不靠删列抬高通过率 |
| rule_validation | 类型/必填/枚举/受限 AST、精度/单位 | 定位 record/field/rule 的 Issue |
| evidence_validation | 来源可访问、span/bbox 存在、摘录相符、对象语义对应 | 无依据或错归属不得无标记作为真值 |
| source_coverage | 全部确认单元的唯一去向与限制 | 未解释范围为阻断 |
| candidate_dispositions | ACCEPTED / NEEDS_REVIEW / EXCLUDED 恰一类 | 计数/归属不一致不发布 |

可选字段 MISSING 且规范允许可 ACCEPTED；必填缺失、冲突/关键歧义仍 NEEDS_REVIEW。EXCLUDED 带原因和适用用户确认，不能仅因难抽取而移除。quality 只属于本 result version；NOT_EVALUATED 不映射成功，PASSED 也不宣传绝对现实真值。

严重事实/对象错误不能仅由规则检测消除，需要独立人工黄金集质量评估。Q01—08 的定义沿用[质量指标](../需求深化/04-非功能安全与运营需求.md)，人工补值和派生/默认单独统计，空分母 NOT_APPLICABLE。



## 九文件明确结构

| 文件 | 内容 | 关键约束 |
| --- | --- | --- |
| standard.xlsx | 空白主表、字段说明/规则与规范版本 | 不含真实行/证据/客户名称/下载引用 |
| standard.json | 可复用 schema、规则、单位与导出策略 | sanitize 白名单，不复制 proposal 全对象 |
| result.xlsx | 目标字段主表 + `_states/_issues/_sources/_excluded` | 主表为所有非 EXCLUDED 候选；状态/问题附表可追稳定 record_id |
| accepted.csv | 仅 ACCEPTED 行、字段顺序与规范一致 | UTF-8 BOM、分隔策略、公式保护声明 |
| result.json | 所有候选、field_status、值/依据引用、移出原因 | decimal 字符串；完整 metadata/schema_binding/result_version |
| issues.xlsx | 问题、影响、可处理动作及来源定位 | 可为空但有表头/版本，不丢未解决项 |
| provenance.jsonl | 记录/字段依据、转换/拆合与决定关系 | 每行完整 JSON，明确 locator_version；不是长期公开 URL |
| validation.json | 六维验证、计数、限制、版本与质量结论 | 对应当前 binding/result，失败/待核不写 PASS |
| manifest.json | 其余 8 文件的 name/sha256/bytes/media_type/version/expiry（固定null） | 不自包含自身 hash；API 返回 manifest 自身 hash |

工作表冲突名、非法字符、31 字符限制以确定性 safe_name 映射记录；本次规范同名附表时为主表生成合法别名并在 manifest 标原名/实际名。目标字段不塞隐藏内部 ID；主表行号与 record_id 的关系在 `_states`。安全导出文本危险前缀先处理前置控制字符，保留 raw 和转义策略；真正数值负数按数值写出，不当公式文本任意加引号。

日期按规范格式，DATETIME 带明确 timezone；CSV 不承诺保留 Excel 所有类型。标准模板反导入能恢复字段 ID/类型/顺序/规则，不把示例作为事实；不能靠隐藏 sheet 存客户原值完成“去事实”。



## 原子发布协议

1. 当前有效 fence 建 artifact_set BUILDING；每文件写 Attempt 独占 staging。文件对象不可覆盖先前已发布 key。
2. 按预期 schema、候选数/去向、列序/格式、证据引用和 binding/result 版本分别回读。CSV/JSON/XLSX 都用独立读取路径抽核，不只检查写文件没有抛异常。
3. 计算 8 文件原字节 hash，写 manifest；再回读 manifest、算自身 hash，校 9/9 齐全、大小/持久保留策略/内容版本一致。
4. 同一 task/run/epoch/fence/未删除取消 guard 下，短事务切 artifact_set READY、result/current pointer、Run SUCCEEDED、operation SUCCEEDED、round reserve CONSUMED、outbox DELIVERABLE及cleanup outbox。
5. 移动/重命名对象并非跨文件/数据库原子事务；实现采用先完成不可见对象、DB 最后发布指针，读端只读取 READY 引用。崩溃遗留对象由 orphan 清理，不对用户暴露。

任一文件失败整体不 READY，不假装 8/9 可交付。0 候选可以生成诊断包，但主表不得造一条假行，严格成表服务不得记已履约；原已付单按合同全额原路退款/售后。诊断包如需取用，类型 DIAGNOSTIC 并明确限制，不冒充成功九文件。



## 私有规范另存与复用

用户主动点保存，API32 指定 binding_id/name/consent，服务端从 SchemaContent 白名单重建，不复制 source/field/evidence/preview 对象。允许：字段名/类型/顺序、抽象业务说明、规则/单位、row_kind、用户确认的抽象用途。禁止：原行值、raw摘录、证据/对象/账户/签链引用、真实业务标识、模型总结里夹带客户秘密。

字段名/描述也可能含真实人名/订单号；保存前敏感检测 + 可审阅摘要，发现疑似真实值提示重写/确认抽象命名。自动扫描不能保证全无秘密，需合成/敏感反例测试。模板样例仅允许明确合成/抽象例值，并标 example_role，不从来源自动带入。

private_template_versions 不可变，更新建新版本；任务绑定固定版本，删除模板仅撤未来复用，不能倒改历史合同/结果。源/结果删除不默认删除用户另存规范；告知独立期限，注销/单独删除按用户选择处理。模板访问仍按 owner，默认不公开/不共享跨平台权益。

### 持久存储与销毁边界

所有九文件必须复制至独立结果区并逐项hash/readback，后端实际持久提交回执成功后再原子发布。仅rename成功、Promise返回、写入OS缓存或把源工作区路径存入DB都不足以证明结果已可靠保存。最终manifest的expires_at为null；下载grant另有短期expiry。

发布事务同时写cleanup outbox，之后Host fence运行环境、停止Agent和工具进程树、撤task读写凭据，清所有本次原件/接收副本/会话/分析/代码/中间/临时/原始日志/检查点及受控spill。核无活writer和残留受控数据后才能标CLOSED。结果记录/问题/必要来源投影存独立生命周期，不能外键级联删掉它们。

来源文件已清理后，结果内的必要摘录与定位仍能解释字段；不能保留整份原件伪装provenance。结果权限校owner，链接到期重新签发；清理不能撤掉正常结果下载。0候选/诊断包按明确服务政策处理，不能冒充正常成表成功；已有持久诊断文件同样与运行区分离。

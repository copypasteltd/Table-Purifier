## 实施细则

## 原生工程与共享边界

两端各自 app、页面模板/样式、组件声明、宿主适配实现、权限/域名/隐私配置与构建产物。shared 只放平台无关 DTO、状态 guard、请求/operation 恢复、数据格式、视图模型与设计 token 转换逻辑。模板层不写 my/tt 条件分支；统一 HostAdapter 由入口注入。

| HostAdapter 端口 | 输入/输出合同 | 开放条件 |
| --- | --- | --- |
| IdentityPort | 一次性凭据 / 明确失败；无客户端自报 subject | 正式 app 和 SDK 认证试验 |
| FileInputPort | 用户主动选择→临时句柄/name/bytes/type；失效可重选 | 每来源入口/OS 真机证明 |
| TransferPort | 许可→上传字节/进度/received；下载→受控临时缓存 | 实测 HTTPS/域名/大小/弱网 |
| PreviewPort | 缓存句柄→可打开请求/结果观察 | 原生/内嵌预览分别证据 |
| ExportPort | 用户选择的宿主合法路径→取用观察 | 真实用户可见文件/转存流程证明 |
| CheckoutPort | 服务端 approved channel payload→客户端观察 | 同 app/SKU/OS 获准；验付仍服务端 |
| LifecyclePort | show/hide/unload/network/keyboard 等归一化 | 最低 SDK 与四环境记录 |
| NotifyPort | 可选提醒授权/失败 | 不以通知权限阻断后台执行 |
| SecureStatePort | 必要 token/IDs 的受控保存、退出清理 | 不存资料正文/商户签名 |

这些是本产品内部接口名，不是任何平台官方 API 名。真实宿主调用、参数/返回、最低 SDK 必须从 W01 接入记录引入，不能照表自造 `my.exportFile` 一类不存在能力。



## 路由、页面与数据

[ui-implementation-map.json](../../assets/development/v3.0.0/ui-implementation-map.json)逐页列 MP01—18 双端同逻辑 route、B 组件、状态、API 和需求。页面唯一主状态来源为 task/run/operation projection，route 只带资源 ID，不能把整份资料/支付参数放 URL。

四根入口保持当前页面规格，根页状态独立；详情返回保留筛选/滚动锚点 IDs，重新查询后确认版本。MP01 首次为空而非设计稿 3 文件示例。MP06 三个字段是展示裁片，真实所有字段可达；MP10 问题卡真实显示当前 evidence/人工状态。其余 15 页沿 B 规则实现，不能声称已有 18 页图稿。

每页实施包含：进入前置、loading/empty/error/offline/stale、主内容、服务端 allowed_actions、禁用理由、提交/未知恢复、无障碍、返回/键盘。不要用一个 success 布尔同时表示执行/质量/文件/付款。



## B 设计的工程化

从冻结 [tokens.json](../../assets/design/b-jade-folders/v1.0.0/tokens.json)生成两端样式变量/常量。保留 canvas #EAF1EE、surface 白、brand #17745E、ink #203C32、资料夹页签/规则线及指定字阶。LU 是 375 宽参考坐标，不是宿主 rpx/dp/pt；版面可按宽度换算，字体与48触控参考不能在320宽机械缩小。

生成输出写 src/shared/design-generated 和各端 build，记录源 token hash；冻结文件原样保留。B-C01—32 的内容/状态/间距/可操作区域按原组件合同落地；设计需要调整时建 B 新版本并更新 active，而非直接修旧图/旧 JSON。

32 组件的责任包括：输入/文件/规范模式、字段列表/编辑、真实阶段进度、记录/问题/来源、按钮/禁用/错误/底部动作、订单与能力说明。每组件有 props/events、busy/disabled/error/empty/long-text 状态、读屏 label/focus 顺序和测试 fixture；不要将同色标签只靠颜色区分。



## 真机与交付证据

每个支付宝/抖音 × Android/iOS 环境记录 app_alias、app build、OS、设备、基础库/SDK、screen/font scale、网络、商品/能力配置 hash。每个输入入口、标准表导入、上传恢复、打开和实际导出各自测试，不能把文字可用等同普通办公文件可用。

320/375/390/430 宽参考、大字号、长中文字段、键盘遮挡、底部安全区、读屏名称/顺序、触控范围实测。静态 token 对比度只是部分证据。B 三锚点 screenshot diff 需容忍宿主系统栏差异，主体布局/信息顺序/状态不可无理由漂移。

导出测试从用户找得到文件并可在获准目标打开入手，保留脱敏录屏/文件 hash/观察事件；模拟器/缓存成功不算。调用浏览器或调试器后关闭本次不用的标签/窗口、卸载轮询和释放缓存；不得关闭用户原有工作页。

### 七步界面状态

MP01准备中→READY前禁用输入；MP05区分免费前置分析与已付批量；MP06采用/确认；MP04仅确认后估费支付；MP08/12只读独立结果；MP17显示清理事实。B框架中的任务/规范/我的查看动作不创建Agent；新处理入口、再次整理和P1调用均先session。清理失败不误标结果失败，结果已保存但环境清理中必须可区分。

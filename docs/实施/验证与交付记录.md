## 真实执行与测试替身的边界

数据库集成测试使用实际 PostgreSQL 18 原生二进制、UTF-8 数据库、12 份迁移、实际应用/Worker 角色和 RLS，不连接系统或其他项目数据库。执行了实际幂等/越权/版本/阶段/实付门槛、九文件写入回读和独立发布、SQL/文件正文清理、结果保留、新会话再加工、原单纠错授权、累计算力预算绑定、主动删除、清理耗尽后的重试、账号 CLOSED 后的删除回执权限。

以上测试明确注入了合成 Agent 输出、初始化收据、已核实支付事实和能力审核替身；它们不是真实模型、真实交易或真实 cgroup 测试。平台测试实际执行签名与原始响应摘要逻辑，但不向支付平台发起交易。小程序控制器在原生 API 测试宿主中执行，并验证输出合同；它没有经过真实宿主渲染。

独立结果验收会识别记录条数相对已确认预估的变化，转为待复核。结果文件可以包含需复核行，不能把“成功产出九文件”描述成“所有数据已经准确通过”。数据库与独立文件销毁通过，不代表上游模型供应商已删除其副本。

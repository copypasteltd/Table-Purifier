# 实际源码技术说明

适用版本：源码 0.1.0，业务 v3.2，P07-DEV 3.0.0，设计 B1.0.0。这里解释实际实现；冻结规格原样保存，实际验收见验证记录。本次只开发源码和本地检查，不执行部署。

## 技术选型与职责

| 层 | 实际选型 | 作用 |
| --- | --- | --- |
| 小程序 | 支付宝/抖音原生 JS、AXML/TTML、ACSS/TTSS | 无 WebView；共用控制器，经 esbuild 生成平台工程 |
| 业务 Host | Node.js、TypeScript、Fastify、Ajv 2020、Zod | 身份、阶段、合同、计费、资金、独立验收和清理的可信边界 |
| Agent | 官方 `@openai/codex-sdk` 0.164.0 与其实际 CLI | 理解、读资料、分析、清洗、推荐规范、写受限处理代码和成表 |
| 文档工具 | 项目专用 Python、pypdf 6.21.3、Pillow 12.3.0、可选本地 Tesseract | 被 Agent 按需调用，不另建固定“解析→模型”业务流水线 |
| 规则与导出 | Decimal.js、ExcelJS 4.4.0、可信 JSON/CSV 生成器 | 精确数值、受限规则 AST、公式防护与九文件回读 |
| 数据库 | PostgreSQL、pg、owner RLS、不可变合同、租约/fencing | 分离应用、Worker、迁移权限；所有金额为安全整数 |
| 隔离与回收 | Linux Landlock、seccomp、非 root、cgroup-v2 | 原生读写边界、资源与进程树回收；不需要容器引擎或虚拟机 |

应用组合根为 `src/application.ts`，实际进程入口为 `src/api/main.ts` 和 `src/worker/main.ts`。小程序源文件在 `miniapp/src`，生成工程可以分别由平台 IDE 打开；本次未发布或进行 IDE/真机验收。

## 两类输入与规范

PROVIDED 接收规范 JSON、字段/规则表单、私有纯规范或规范文件；DISCOVER 由 Agent 从本次全部资料中推荐字段、类型、必填、单位、记录粒度、标识键、规则及限制。两类都必须完成全范围分析、用户采用、执行方案确认后再估费。

当前可读取文本/JSON/CSV、XLSX、DOCX、PDF 和 PNG/JPEG。UTF-8、UTF-16、GB18030 文本有实际工具测试；加密文档、过大压缩包、不可读扫描页等明确拒绝或标为待确认。扫描 PDF 暂不提供自动逐页 OCR，需重传可读文件或图片。图片 OCR 使用被配置且受限的本地 Tesseract，不假定其已安装。

原生小程序办公文件选择能力受具体宿主 API 和设备证据约束，默认关闭。后台真实文件上传通道已实现，但不能据此宣称两端已具备任意办公文件选择器；文字粘贴和图片入口独立存在。

规范编辑保留七类字段、标识键、locale、时区、舍入、导出保护和完整规则。页面提供常用比较/条件必填规则，复杂规则在编辑时保持不丢失。Excel 规范通过可见的 `__P07_SCHEMA__` 页携带完整 JSON、分块和 SHA-256，导入要核对顺序及摘要，不从截图猜测隐藏规则。私有规范只保存纯定义，须单独同意并人工检查描述中没有事实资料；版本不可变，逻辑停用和隐私物理删除分开。

## 会话与模型隔离

`loadFullSkill` 核对七份实际资源的路径、UTF-8、字节数和 SHA-256，拼接完整正文；上下文不够就拒绝，不能降级为摘要、目录索引或按需读取。BOOTSTRAP 只接受初始化标识和 Skill 版本，不携带客户目标或内容。READY 还要求完整组合收据、原生物理隔离探测和 Agent 初始化完成。

每个会话使用私有 HOME/CODEX_HOME、工作/临时目录与模型代理 token。代理限本会话、固定模型、完整 Skill、响应大小、总调用量及授权文档工具，禁止外部托管工具、历史复用和上游保存请求。上游真实数据处理方必须与隐私政策一致；供应商的保存或删除能力不能被本地清理代替。

原生启动器固定可执行文件和摘要、最小系统只读根、仅本项目 Python 依赖及本任务目录。任务无数据库或商户凭据，不继承桌面认证。cgroup 限内存、进程和 CPU；seccomp 拒绝跨进程读取/信号、危险内核接口及文件权限变更。正式 READY 依赖真实 Ubuntu canary 探测，单有 cwd、workspace-write、可编译 C 或一份配置不算验证通过。

## 可信计费与资金

确认合同绑定资料集合、目标版本、规范摘要、执行方案、Skill、预算与价格策略。估费由 Host 使用测量单元和整数价格计算，不接受 Agent 或客户端报金额。配置金额只是策略，实际收银还须匹配平台/系统/宿主/SDK/构建、SKU、原单位与有效证据。

支付宝使用 RSA2 和原始响应签名检查；抖音采用通用交易与原始签名数据核验。客户端支付完成只触发状态查询。只有已确认的原平台实付事实能创建 PAID 权益；UNKNOWN、未付、过期/撤销合同或普通 FREE 均不能生产。人民币分与抖音钻石使用不同原单位，不能隐含换算。

订单重进恢复原任务，抖音重试仅更新同一订单收银签名的 nonce/时间，不创建第二个商户订单。退款预留、成功入账、失败释放与事实唯一键避免超退/重记。外部未知退款回调会撤权、停止相关处理并进入待对账，不能把未知事实当作零退款；这类异常需售后在原平台核对，当前不提供自动导入平台全量账单。

模型批量累计预算为 900 秒。先锁原预算合同预留，再释放并记实际消耗；崩溃后的未释放预留按保守方式保留，不放大剩余预算。普通用户再次加工须重新确认/估费/核实付款。原资料遗漏或提取错误经运营审核后可绑定原实付订单，但不能新增事实范围、重置累计预算或消耗用户修改轮次。

## 再加工与平台纠错

用户修改问题时，先建立新 Session 并完整预载，READY 后才展示可提交的修改表单。决定预览绑定结果版本、具体记录/字段/证据、影响范围和摘要，正式提交仍须匹配。新任务显式导入所选父结果，原件已销毁时重新上传必要原件。Host 独立检查 USER_VALUE 的类型和精确值、保留未解决状态以及选择证据的原内容锚点，Agent 不得偷偷换值或遗漏已选记录。

平台纠错另建新会话，重新分析、确认、估费，用户对当前任务作最长 24 小时的售后读取授权。运营审核绑定当前新合同、方案摘要、原始文件摘要和原实付订单；新事实不被纠错权益覆盖。审核通过后由原订单 PAID 权益启动子 Run，原结果版本不被覆盖。旧 CLOSED 环境不会恢复。

## 独立验收与结果持久化

Host 校验候选规范、完整计量范围、字段类型、精度、受限规则、证据原文子串、定位、用户决定和标识键重复情况，重新计算 disposition、计数、质量和清单。Agent 自报 accepted、金额、validation.json 或 manifest 都不是验收结论。

覆盖 READ 证明所列读取单元得到处理，不能数学证明语义上没有漏行。若候选条数与已确认方案预估不同，Host 增加记录数变化阻断项，整批进入待复核；条数相同也仍需要真实业务资料验收。DERIVED/DEFAULTED 值在尚无可独立复算规则时保留为需复核，不能冒充可靠事实。零候选不计正常交付成功，会停止处理并核对原单退款。

结果九文件先写独立结果区，逐项 fsync、回读摘要并核对固定名称；数据库原子提交结果版本与清理 outbox。结果区不在任务运行区内。发布成功后，清理器停止整棵 cgroup 进程树、撤销任务工作区，清除输入、模型会话、用户控制正文、脚本、工具结果、临时文件、OCR、日志/检查点及 SQL 中非结果正文副本。清理失败真实重试，不能提前写 CLOSED。

正常清理保留结果九文件、必要结果/问题/证据投影、经单独同意的纯规范、最小支付事实和清理回执。结果领取令牌绑定 owner、结果版本、单个文件与期限；发放和下载都核权限，重新回读文件摘要，支持受限 Range。

小程序可以领取并打开 Excel；JSON/CSV 等也可经用户明确确认，复制单文件五分钟领取链接到自己的浏览器。复制到剪贴板属于另一次明确用户操作，不自动分享，不将复制成功写为文件保存成功；持有短期链接即可领取，因此界面在复制前说明范围与有效期。平台 API 参考：[支付宝 my.setClipboard](https://pds.alipay.com/docs/miniprogram/mpdev/api_device_clipboard_setclipboard)、[抖音 tt.setClipboardData](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/api/device/pasting-board/tt-set-clipboard-data)。抖音需在平台隐私声明与授权中满足剪贴板权限；四环境实际领取与复制仍为 NOT_RUN，EXPORT 门槛默认关闭。

## 主动隐私删除与恢复

TASK_CONTENT、PRIVATE_TEMPLATE、ACCOUNT 三种明确范围立即撤销访问，再排队清理。账号删除撤销其他登录，当前登录只用于删除进度及必要退款信息；清理完成后账号 CLOSED，只允许操作/删除回执读取，并把该登录期限缩至最多 24 小时。

账号注销会清除平台标识密文、私有规范、售后正文和正文幂等响应。私有规范物理删除也清除可能携带规范正文的幂等缓存。页面只保存删除请求 ID，重进可以查询；PARTIAL_FAILED 可对同一请求重试，不恢复业务访问。已下载到个人设备的副本不受服务端删除控制。

## 权限、异步与故障恢复

owner 由已验证的登录 token 取得，SQL 事务 SET LOCAL 后由强制 RLS 隔离。应用角色不能是超级用户、BYPASSRLS 或 schema 所有者。迁移角色和跨租户认领 Worker 接口分离；Agent 不访问数据库。

幂等键与规范 JSON 摘要绑定。同键同正文返回同结果，同键异正文 409；已清理正文的历史响应返回 410 并要求读取当前资源。后台使用行租约、心跳、递增 fence 和发布锁；旧 Worker 失权后不能发布。持久化重试复用既有候选，不重新收费或再次请求模型。健康 ready 对完整迁移列表与每份 SHA-256 一致性进行检查。

用户接口不输出 SQL、原异常、商户密钥或请求正文。运营接口使用独立 token 摘要，并且读取客户内容还必须有具体任务的未过期限时授权。公网日志仅保留必要代码/请求标识；部署环境的反向代理、平台留存、备份和日志政策仍需未来真实接入时核验。
